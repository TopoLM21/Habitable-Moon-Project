# Перенос энергии и преднапряжения при смене материального отсчёта

08.10.2026, ветка `fix/genesis-mantle-convection`. Компонент915: два новых
Python-файла поверх сохранённых913. Область: локальная ковариантность
заданной плотности энергии; физическая подготовка материала не выполнена.

Для фиксированной по механическим координатам карты `B=dXnew/dXold`,
`J=det B>0` реализовано:

```
Fnew = Fold B^-1
Wnew(Fnew,z) = Wold(Fnew B,z)/J
dVnew = J dVold
Pnew = Pold B^T/J
Hnew = L^T Hold L/J
```

`L` содержит полный перенос девяти компонент F и единичные блоки
дополнительных внутренних каналов. Смешанные производные не теряются.
При переносе на моды учитываются обе части жёсткости:
`D^T H D + sum_a P_a Q_a`, включая кривизну, сопряжённую преднапряжению.
Вычисление использует exact Fraction или outward FractionInterval;
неположительный либо не удостоверенный положительным J отклоняется.
Перенос через обратную карту возвращает исходный полный two-jet.

Сохраняются полная энергия, виртуальная работа, модальный Hessian,
пространственный тензор напряжений и результирующая на преобразованном
материальном векторе площади. Одной единичной нормали для последнего
равенства недостаточно: преобразуется весь вектор площади `cof(B) N dA`.
B может зависеть от материальной точки, но не от дифференцируемых мод;
для зависящей от мод карты нужны дополнительные производные B.

Собран объявленный оператор `R101(q,q̇)=∇U(q)−Qbasal(q,q̇)`.
Каталог содержит6 координат конечных поворотов владельцев,30 HOT,

Производная по состоянию равна `H_U−Kbasal`, по скорости — `D`.
Скорости заданы явно в физических единицах, включаяλ.

Холодная энергия использует совместное состояние тела и подготовки.
Для подготовленной отсчётной точки `X0`, её модальных полейψ и
относительных градиентовG вычисляются `y=X0+Σcψ`, `B=I+ΣcG`.
В законе `Tλ(y)=Qλ(y)y` пространственный градиент имеет вид
`DTλ=Qλ(I+λd(y))`. Ортогональная левая матрицаQλ сокращается в
тензоре Грина, поэтому используется полный
`E=((I+λd)B)ᵀ((I+λd)B)/2−I/2`.
Смешанные производные по56 координатам иλ включены; складывать
две отдельные прежние энергии для этой цели нельзя.

Новые моменты интегрируются по полной исходной объёмной мере
`R²cosβ dθdβdz`, один раз. Сохранены8 исходных родителей, оба слоя,
три угловые части и весь материал трёх архивных когорт. Разбиение
по умолчанию содержит408 ячеек: активную модальную область,
нулевое модальное дополнение и настоящий донорский воротник.
В воротнике используется равномерное ограждение настоящей карты887,
её радиального сокращения и обратного градиента; история активации
не заменяется нулём. Старые Gram и обратный Gram взяты из899 без
повторного прежнего интегрирования. Восемь буквальных исходных
энергий, сил и жёсткостей входят один раз, с нелокальной проекцией
и кривизной преднагрузки.

HOT сохраняет закон903, конечное среднее и все вторые производные
неявного среднего. Исходные16 контактов используют32 подлинные
стороны:24 LIVE и8 архивных. На каждом материальном ярлыке

градиента; плечо переносится через полный исходный мост, включая

Повороты владельцев заданы конечной экспоненциальной картой с

Базальная часть сохраняет закон931 и68 исходных положительных
весов:59 холодных и9 HOT. Парная поправка уже включена в веса.
Материальные поля поворачиваются конечной картой с полными

исходныеΩm, a(q) иRsource сохранены. Прежний потенциал нагрузки

мантии. Нужна нижняя граница прироста общего потенциала приλ=1

будет доказанная необходимая длительность либо дефицит работы;

На немодальном дополнении поляψ/G/H равны нулю. Чтобы сохранить его
энергетический вклад при общих холодных координатах, требуется явно
удостоверить разложение ортогонального остатка899/935. Минимум каждого
внутреннего элемента получается из полной формы
`E0+f(p+r)+K(p+r)²/2`; релаксация16 контактов ограничивается суммой
`ΣArea·Φ(anchor)`, с сохранением исходных постоянных энергетических
смещений. Для HOT нужна неотрицательность исходного
закона на допустимой карте конечного среднего. Численную границу923
для нулевых56 координат автоматически переносить на общий101 нельзя.

Мощность определяется пространственным законом931:
`τ·u−β|u|²≤|τ|²/(4β)`. Ограждениеτ должно использовать допустимые

обобщённой мощности. Это чистая мощность после сопротивления;

Что добавлено

genesis_volume_fracture_surface.py: две стороны сопоставлены при общей
физической глубине lambda, а не при одинаковом массовом q. Сетка глубины
разбивается по фронтам когорт обеих сторон; сохраняются отдельные q bounds,
cohort/owner/material IDs. Непарные твёрдые хвосты учтены отдельно, без стоимости
парной поверхности. Reference support x=lambda[(1-s)Xu+sXv],
dA=lambda|Xu cross Xv| ds dlambda. Площадь Gamma считается ОДИН раз;
Gc включает обе созданные стороны. Полный A_xyz/P_xyz trace имеет 24 local DOF,
force сопряжена с trace по работе. Это пока вычислительная radial reference
опора заданного edge cycle, не выбранная из Genesis sharp fracture plane.

genesis_volume_creation_law.py: явно заданный cohesive закон без defaults.
Раскрытие и два касательных скачка определяют effective separation;
maximum separation хранит необратимую память. Учитываются упругость,
разупрочнение, разгрузка/повторная нагрузка, полное разделение и обратимое
сжатие. Работа вдоль прямых fixture gap segments точно равна
delta stored energy + delta fracture dissipation.
При полном разделении диссипация равна Gc на единицу исходной Gamma, без
повторной платы после разгрузки. Это ядро без нового трения/вязкости.
Четырёхточечная spatial quadrature точна для квадратичного trace energy;
для нелинейного cohesive ответа это явно дискретная пространственная модель.
Независимый audit интегрирует traction по сегменту пути с разделением событий.

genesis_volume_creation.py: контекст связан с целым принятым checkpoint,
clock/steps, geometry/history/e0/e1/fault/thermal и буквальными журналами работы.
Вычислительная cohesive история сохраняет весь принятый путь и воспроизводит
его при загрузке. Это отдельная история от нулевого fixture origin, не замена
prestress планеты и не restart настоящего активного разлома.

В самом принятом Genesis активных плоскостей по-прежнему 0;
actual_cut_status=no_eligible_cut, actual creation law неизвестен.
Пример Gc=1e6 J/m2, T=4e6 Pa, k=1e9 Pa/m, kc=2e9 Pa/m явно вычислительный,
не калибровка материала Genesis. Источник E/strength/diffuse damage не задаёт
независимый Gc. Упругая энергия полосы, прежняя damage-energy change,
friction/viscous loss и defaults другой ветви не выданы за этот параметр.
Ни physical cut/release/contact, ни списание creation work в Genesis не выполнены.

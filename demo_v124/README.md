# v0.24 500-Myr subdivision-4 demo

This directory contains selected outputs from the fixed-seed (`20260806`) 5,120-cell validation run using `dt=4 Myr` for 500 Myr.

- `summary_v124.json` — complete machine-readable final diagnostics;
- `craton_history.csv` / `.png` — maturation history;
- `craton_strength_final.png` — final 0–1 strength memory;
- `continental_lithosphere_age_final.png` — effective root age;
- `mantle_depletion_fraction_final.png` — compositional-depletion proxy;
- `mantle_lithosphere_thickness_final.png` — mechanical mantle-root thickness;
- `plate_map_final.png`, `elevation_final.png`, `surface_relative_sea_level.png` — final surface/plate context;
- `sediment_thickness_final.png` — retained v0.23 conservative sediment layer;
- `topology_events.json` — all split/merge/absorption events.

The complete numerical interpretation and validation limits are documented in `../V124_CRATON_FINDINGS.md`.

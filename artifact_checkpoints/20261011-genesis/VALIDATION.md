# Проверки контрольной точки

Эта запись относится к полному первоначальному локальному коммиту `baa4fd4`.
Проверки отдельного публикуемого коммита и ветки данных:
[PUBLICATION_VALIDATION.md](PUBLICATION_VALIDATION.md).

В этой задаче менялись план, правила сохранения точных байтов и инструменты
архивации/восстановления. Численная модель и принятое состояние Genesis
не изменялись.

- Все **469** исходников последнего численного пакета совпали с закреплёнными
  SHA256 после подготовки коммита.
- Сжатый архив проверен полностью: **848 файлов / 168 988 891 исходных байт**,
  включая сравнение с каждым текущим оригиналом; запись при проверке не
  выполнялась.
- Помощник восстановления прошёл **14 синтетических проверок**, включая
  повреждённые части, CRC, дублирование/обход путей, симлинки, конфликты
  существующих файлов, свободное место и восстановление внешних якорей.
- Контрольный исходный CSV с CRLF даёт одинаковый Git blob ID с фильтрами
  и без фильтров при новых правилах `.gitattributes`.
- Полная сверка подготовленного индекса с точными рабочими байтами записана
  в [index_byte_verification.json](index_byte_verification.json).

Последние **80 численных тестов PASS** и независимые проверки 10 144 выбранных
интегралов относятся к предшествующему численному этапу. Его исходники
не изменены; длительный численный расчёт в задаче подготовки коммита повторно
не запускался. **Четыре угловых расчёта остаются OPEN.** Проверки архива
и Git не пересчитывают численный вердикт и не допускают физическое событие.

`git diff --cached --check` для текущих исходников, тестов и драйверов
отметил **10 лишних пустых строк в конце ранее созданных файлов**:

```text
analysis/genesis_cohort_mechanics_validation/verify_output.py
analysis/genesis_volume_location_validation/independent_audit.py
analysis/genesis_volume_seed_validation/independent_audit.py
tectonics/geometric_native_common_cold_depth_preparation.py
tectonics/geometric_native_common_coupled_cold_energy.py
tests/test_genesis_volume_seed_independent.py
tests/test_geometric_native_common_cold_depth_preparation.py
tests/test_geometric_native_common_mixed_force.py
tests/test_geometric_native_implicit_force_support.py
tests/test_geometric_native_solid_layer_placement.py
```

Эти файлы сохранены без форматирующих правок: задача фиксирует накопленную
контрольную точку, а шесть из перечисленных файлов входят непосредственно
в последний закреплённый набор из 469 исходников. Проверка форматирования
поэтому имеет эти известные замечания; её результат не объявляется PASS.
Новые план, правила Git, README и помощник восстановления таких замечаний
не имеют.

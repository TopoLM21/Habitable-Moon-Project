# Запуск GPU через GUI

2026-09-09, ветка `perf/gpu-compute`.

## На подготовленном компьютере

1. Запустите `launch_gui.bat` из этой GPU-папки.
2. В поле «Режим расчёта» выберите **«CPU + GPU — поверхность (CUDA)»**.
3. Для единственной видеокарты оставьте «CUDA-устройство» = **0**.
4. Для двух новых CPU-ускорений включите **«Компактный подбор соответствий
   (CPU)»** и **«Пакетные граничные силы (CPU)»**.

По умолчанию сохраняется оптимизированный CPU-режим; обе новые галочки
выключены. Их можно включать независимо в CPU- или GPU-режиме. Во время
работы и безопасной паузы параметры вычислителей заблокированы. Чтобы поменять
режим, остановитесь на готовом checkpoint и запустите продолжение с новыми
настройками. GPU обрабатывает только поверхностный блок; прочая физика и обе
новые оптимизации остаются на CPU. Приближённый `--gpu-arcs` в GUI не включён.

При ошибке CUDA расчёт останавливается; причина выводится во вкладке «Журнал».
Скрытого переключения на CPU нет. Для осознанного CPU-запуска выберите CPU
в списке. Открытие самого окна не требует инициализации CUDA.

## Первичная установка или другой компьютер

Установите Python **3.12** и запустите `setup_gui.bat`. Скрипт создаёт локальную
`.venv` при её отсутствии, устанавливает GUI/CUDA-зависимости из
`requirements-gpu.txt` с версиями CPU-библиотек из
`requirements-performance-lock.txt`, затем проверяет зависимости.
По умолчанию интерпретатор выбирается через `py -3.12`. Если он не
зарегистрирован в Windows launcher, передайте полный путь:

```bat
setup_gui.bat "C:\path\to\python.exe"
```

Нужны совместимые NVIDIA GPU и драйвер для режима CUDA. Установочные пакеты
занимают сотни мегабайт; существующий pip-кэш может избежать повторной
загрузки. Скрипт не устанавливает драйвер и не меняет системный Python.
После успешной установки используйте `launch_gui.bat`.

BAT запускает именно `.venv\Scripts\python.exe` рядом с ним. Отдельная
активация окружения не нужна. На текущем компьютере оно уже создано,
зависимости установлены локально; больше не нужны `work/gpu-probe-env` или
`PYTHONPATH` от CPU-папки. Обычная зависимость venv от базового Python остаётся:
не удаляйте интерпретатор, которым оно создано. `.venv` не входит в Git и не
копируется между компьютерами — на новом месте повторите установку.

Без пользовательских переменных окружения CUDA/CuPy/Matplotlib-кэши для
GPU-процесса создаются в `<результаты>/.cache/`. Явно заданные пользователем
пути сохраняются. Выбор режима/устройства/галочек записывается в `gui_run.json`,
а факт выполнения CUDA и новых алгоритмов — в `render_timings.json`.

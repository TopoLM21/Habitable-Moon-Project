# Контроль ошибки на целой ячейке: спецификация первого прототипа

База: `59a26f719482fc4b0fac8da692f87ff65622d3b1`.
Только проектирование по сохранённым исходникам и результатам. Интегратор
не реализован, новых прогонов нет, 2e−6 и действующие лимиты не изменены.

## 1. Объект и область первой гарантии

Для начала — **скалярный объём обеих сторон Γ** в уже сохранённом примере
касания, без деформации. Сертифицируется интеграл буквальных исходных
параметров, а не угловая квадратура как таковая. Общий тензорный оператор
пока не входит в доказанную область применимости.

Использовать исходный веер из трёх треугольников. В каждом:

```
N(ρ,t) = a + ρ((1−t)b + tc − a),   ρ,t ∈ [0,1],
λ ∈ [λlo, λhi],                   x = λ N X  (для первого примера),
K(ρ,t,λ) = Atri · ρ · det(X) · λ²,
Q = ||x − center||² − R²,         G = normal·x − offset.
```

`Atri` — положительная удвоенная площадь в координатах N1,N2, не площадь
физической грани. Искомые интегралы: `I± = ∫ K · 1[Q≤0] · 1[±G≥0]`.
Фактор λ² и угловой якобиан уже включены; второй раз их не применять.
В первой геометрии det(X)=160>0. Общая положительная ориентация должна
быть доказана, а не предположена по выборочным узлам.

**Ключевое отличие:** блоки строятся в исходных ρ,t,λ, а не между корнями
событий на отдельных лучах. Не нужны производные движущихся корней,
интерполяция корней между t-узлами или предположение о постоянной их кратности.
Цена этого выбора — возможные широкие границы и медленное уточнение границ
области; гарантии сходимости в заданном бюджете нет.

## 2. Конкретный алгоритм включения интеграла

Начальная область — три полных прямоугольных блока, по одному на треугольник.
Каждый блок B хранит точные рациональные границы, глубину и интервалы
интегралов обеих сторон. Разбиение двоичное по середине одной координаты;
в первом прототипе оси ρ,t,λ чередуются по глубине. Это фиксированное
правило для проверки границ, не новый индикатор эффективности деления.

Для каждого блока:

1. Подставить его аффинные координаты в Q, G и K. Представить полиномы
   в тензорном базисе Бернштейна на единичном кубе **точно рационально**.
   Минимум/максимум коэффициентов включают значение полинома на всём блоке:
   базисные функции неотрицательны и в сумме равны единице.
2. По Q и знаку G классифицировать каждую сторону. Например, `inf Q>0`
   или `sup(±G)<0` доказывает пустоту; `sup Q≤0` и `inf(±G)≥0` доказывают
   включение всего блока. Промежуточный случай — **неопределённый**, не пустой.
   Точные дополнительные доказательства разделения сферы и плоскости
   допустимы только в собственной подтверждённой области применимости.
3. Пустой блок даёт [0,0]. Полностью внутренний блок даёт точный интеграл
   полинома K. Его можно получить интегрированием мономов или средним
   коэффициентов Бернштейна, умноженным на меру блока.
4. Для неопределённого блока с `K(B) ⊂ [l,u]` использовать
   `J(B) = |B| · [min(0,l), max(0,u)]`. Для неотрицательного объёма это
   [0, |B|u]. Неизвестная доля занятого объёма не заменяется долей ненулевых
   проб. Никакие полосы касания и пропущенные корни не вычитаются.
5. Суммировать J(B) по текущим неперекрывающимся листьям. Уточнять лист
   с наибольшей шириной включения, нормированной фиксированным допуском
   компоненты; при нулевом допуске положительная ширина имеет приоритет.
   При замене родителя детьми проверять точное покрытие. Можно пересечь
   сумму дочерних интервалов с сохранённым родительским интервалом: оба
   включают один интеграл. Старый и новый вклады одновременно не суммировать.
6. Перед выделением детей резервировать их стоимость. При исчерпании
   лимита вернуть последний корректный интервал и `UNRESOLVED`, не PASS.

Нижняя точность вычисления знака только расширяет неопределённую область.
Она не может стать основанием для исключения блока. Равенство на обычной
поверхности Q=0 или G=0 не меняет объёмный интеграл. Если G тождественно
нулев на объёмной области, нельзя автоматически отнести её к обеим
сторонам: нужен отдельный физический договор о принадлежности либо отказ.

## 3. Почему ошибка не недооценивается

Для каждого q∈B индикатор области равен 0 или 1. Поэтому на неопределённом
блоке произведение индикатора на K принадлежит выпуклой оболочке {0}∪K(B),
включая **знакопеременные** компоненты. Интегрирование этого поточечного
включения даёт шаг 4. На остальных блоках используется доказанное
отсутствие вклада либо точное интегрирование. Аддитивность интеграла на
точном разбиении даёт `I ∈ [L,U]` независимо от порядка уточнения.

Для любой представленной оценки v, включая старую Q55:
`Ecert = max(|v−L|, |U−v|)` ограничивает настоящую абсолютную ошибку.
В первом опыте проверять именно сохранённую Q55 и её исходный компонентный
допуск; не выбирать v или масштаб допуска по известному объёму сферы.
Новые интервалы в общем случае не обязаны быть узкими.

Старый фильтр `8Σ|Q55−Q33| + source_error` сохраняется в отчёте **отдельно**.
Сертификат не подменяет его вердикт без отдельного решения о приёмке нового
контроля. Первый опыт — сравнение сертификата с прежним результатом;
он не разрешает большие контроли при нынешнем отрицательном малом наборе.
Для будущей строгой относительной гарантии можно дополнительно требовать
`Ecert ≤ 2e−6 · dist(0,[L,U])` и соблюдения прежнего допуска. Если интервал
содержит ноль, чистая относительная гарантия этим способом не получается;
точный ноль требует доказательства, абсолютный допуск нельзя изобретать.

**Неопределённость учитывается один раз.** В первом прототипе интервал
получен напрямую из буквальных исходных полиномов, а v — фиксированное
представленное число. Поэтому прежняя [0,Uroot] не добавляется к нему
вторично: корневые области уже покрыты блоками. Прежний source-бюджет
остаётся видим в прежнем фильтре. При будущей комбинации методов каждую
область следует закрепить за одним способом включения; нельзя одновременно
использовать старую глобальную Uroot и повторно учитывать ту же область.

## 4. Гладкость, события и переход к тензорам

Для базового включения не нужна гладкость индикатора области. Нужны
измеримость, интегрируемость и конечная достоверная граница плотности на
каждом блоке. Касания, слияния корней и смена количества ветвей дают
неопределённые блоки. Границы λ когорт включены в разбиение; при нескольких
когортах сначала разделить их, сохранив правила общей границы.

Для первого скалярного примера всё необходимое полиномиально:
Q имеет степени не выше (2,2,2), G — (1,1,1), K — (1,0,2).
Производные не нужны. Для общего оператора нужно реализовать
`enclose_density(B, component)` с доказанной включающей границей **на всём
блоке**, включая коэффициенты материала, память, якобианы, знаменатели
и применимые ветви формулы. Если знаменатель включает ноль или ограниченность
не доказана, ответ — отказ/неограниченный интервал, не нулевой вклад.

Имеющиеся границы радиального интеграла в фиксированной N **не являются**
таким интерфейсом. Нынешняя Uroot доказана только для трёх скалярных
геометрий; переносить её на знакопеременные тензорные компоненты нельзя.
Границы всего тензорного поля и допустимость обращения его знаменателей
на блоке сейчас **не предоставлены и не доказаны**.

Возможное последующее сужение: на доказанно внутреннем гладком блоке
построить полином P и доказать `K−P ∈ R(B)`, затем интегрировать P точно
и прибавить |B|R(B). Интерполяция сохранённых узлов сама по себе R не даёт.
Для остатка Тейлора нужны включающие производные требуемого порядка на
всём блоке; таких границ в сохранённых данных нет. Альтернатива — прямая
интервальная оценка выражения K−P, которая может оказаться слишком широкой.
Пересекающие события блоки не получают гладкий остаток без отдельного доказательства.

## 5. Проверка применимости по уже сохранённым данным

- [Исходники скалярного вычислителя](analysis/genesis_volume_banks_validation/independent_bank.py)
  используют детерминант X и интеграл λ²; сохранённая геометрия без деформации
  соответствует полиномиальному K выше. Это проверка структуры, не новый прогон.
- [Последний отчёт](analysis/genesis_volume_residual_validation/README.md)
  и узлы подтверждают наличие касаний и взаимодействия осей. Обоснования
  глобальной гладкости по t они не дают; новый базовый метод её не требует.
- [Прежний геометрический аудит](analysis/genesis_volume_residual_validation/independent_audit.json)
  охватывает 581 записанный луч, 931 корень и 107 листьев. Это полезные
  регрессионные случаи, но отсутствие других событий между лучами из этого
  не следует. Поэтому новая классификация делается на всём блоке.
- Ошибка старых направлений до 4,23 раза и неудача малого набора остаются
  фактами. Они не опровергают включение по Бернштейну, но и не показывают,
  что его ширина достигнет 2e−6 при прежних лимитах.

## 6. Минимальная реализация, проверки и первый будущий опыт

Порядок реализации после отдельного поручения:

1. Точное преобразование полиномов и проверяемый сертификат блока:
   исходные коэффициенты, границы блока, Bernstein-коэффициенты, классификация,
   интервал интеграла и связи родитель/дети. Независимый аудитор восстанавливает
   полином и покрытие, не доверяя записанному решению о пустоте.
2. Контрпримеры с известными интегралами: полином, исчезающий на всех узлах
   3/5, должен иметь ненулевой сертифицированный вклад; узкая положительная
   область без узлов не должна исчезать; знакопеременная плотность в
   неопределённой области должна сохранять отрицательную границу.
3. Γ через вершину/ребро, касание и двойной корень сферы, разделение когорт,
   тождественное G, нулевой знаменатель, исчерпание бюджета. Проверить
   включение известного интеграла, а не близость двух правил; подмена знака,
   пропуск блока и уменьшение верхней границы должны обнаруживаться аудитом.
4. Только после этих проверок — **один скалярный пример касания целиком**,
   три начальных веерных блока. Сохранённая Q55 — сравниваемая оценка;
   аналитический объём используется только для независимого контроля
   полученного интервала, никогда для его настройки. Полушары и тензоры —
   следующие отдельные этапы, не автоматическое продолжение первого опыта.

Измеримая граница предлагаемого первого опыта, без увеличения лимитов:

- **0 новых радиальных вызовов**: Q55 уже сохранена; это не означает нулевую
  стоимость новой интервальной работы. Старые затраты не списываются.
- Не более **2000 обработанных блоков суммарно**, включая родителей и
  λ-подразбиения; это более строгий общий счёт, а не 2000 угловых блоков
  плюс скрытый неограниченный радиальный расчёт. Глубина не более **24**.
- На блок — одно преобразование каждого из Q,G,K: не более 27+8+6
  рациональных Bernstein-коэффициентов для этой фиксированной геометрии.
  Это ограничение числа коэффициентов, **не числа битовых операций или
  времени**. Для обеих сторон используется один G. Никаких внутренних
  неограниченных поисков корней или скрытой вложенной адаптации.
- Лимит радиальных вычислений **3400 остаётся неизменным**; первый опыт
  его не использует. Отдельно измерить количество обработанных блоков,
  преобразований и битовую длину рациональных чисел, память, фактическое
  время, ширину интервала и Ecert/допуск. Их текущих замеров нет.

Если границы широки после исчерпания бюджета, результат — корректный
`UNRESOLVED` и измеренная причина. Расширение бюджета, замена критерия
приёмки и запуск больших контролей этим проектом не разрешаются.

Эта спецификация даёт условное доказательство включения для первого
скалярного прототипа. Она не обещает узких границ, не решает недостающий
общий тензорный интерфейс и не закрывает физические условия первого этапа.

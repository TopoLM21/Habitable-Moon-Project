# Мост данных Genesis → Starter/mature, версия 1

Реализован отдельный opt-in интерфейс `tectonics.genesis_transfer_bridge`.
Он создаёт проверяемый пакет обмена, **не runnable mature checkpoint**.
Существующая тектоника и её настройки не изменены. Первый рубеж начат:
транспорт данных закончен, физическая передача в расчёт остаётся заблокирована.

## Контракт

`write_bundle(destination, packet_path=..., cuts_path=..., source_path=...,
expected_sha256=...)` принимает закреплённые байты сохранённого conical/fixed-cut
состояния. В новом каталоге сохраняются исходный packet, поставщик геометрии
cut-cells, канонический source, `transfer.json` и SHA256-манифест. Существующий
каталог не перезаписывается. Нормализации строк нет. Несовпадающие часы,
массы, material IDs, геометрические привязки и нечисловые значения отвергаются.

`read_bundle(path)` проверяет хеши и заново вычисляет все производные поля.
Изменить derived-поле и только переписать его хеш недостаточно. Внешние
закреплённые хеши устанавливают идентичность входов, а не физическую
приемлемость произвольного trial; при чтении перенесённого пакета следует
сверять манифест с доверенным отчётом. Хеши не являются цифровой подписью.

Пакет содержит:

- Массу и энтальпию твёрдых когорт по исходным граням. Остальные тепловые
  резервуары сохраняются отдельно, с исходными индексами. Остатки округления
  группировки явно записываются; полного теплового профиля никто не обнуляет.
- Глобальную вращательную проекцию скорости и **обязательный полный остаток**.
  Их линейные/угловые импульсы, кинетические энергии и ошибка реконструкции
  записаны отдельно. Проекция не создаёт плит; энергия остатка не становится
  теплом. Перенос только вращательной части не удовлетворяет контракту.
- Повреждения и всю историю fault_history, орбиту, исходную упругую энергию;
  по каждой грани — средние по массе коэффициенты strain0/strain1, а по каждой
  когорте — остатки и IDs. Полные исходные температурные, геометрические,
  временные и механические данные остаются в закреплённых файлах.

Средние коэффициенты — **описательное агрегирование**, не новая реология.
Их RMS-остаток измерен в пространстве коэффициентов, не является ошибкой
напряжения или энергии и не ограничивает её автоматически (радиальные
коэффициенты могут компенсироваться). Поэтому эти средние нельзя подставить
в существующий закон повреждения вместо исходной памяти. Для точных напряжений
нужны исходные данные и прежний оператор. Никакой допустимый физический порог
ошибки в этой версии не придуман.

## Условия допуска

Уточнение: эти условия относятся к **прямому mature handoff**, а не к входу
в Starter. Одна связная оболочка допустима для native Starter. Отдельный
`assess_starter_entry` и [ограниченная проверка](../genesis_starter_bridge_smoke/README.md)
различают эти два пути; объёмный пакет блокирует отсутствующее активное
замыкание памяти, не отсутствие первого разделения.

`checks` перечисляет необходимые условия: подтверждённый первый раскол,
пригодность первичного твёрдого резервуара по правилам Starter, консервативный
перенос на каноническую сетку, активное замыкание памяти/импульса и тепловых
резервуаров, обоснованные остальные mature-поля. Число владельцев само по себе
не доказывает физический раскол; наличие твёрдых cut-cells не доказывает
пригодность всего первичного резервуара. Такие условия помечаются UNPROVEN.

`require_admission` в версии 1 всегда запрещает физический запуск: существующий
потребитель не развивает эти остатки и полные тепловые резервуары. Даже
отредактированный флаг `physical_handoff_admitted=True` не открывает запуск.
Это ограничение версии интерфейса, а не утверждение, что зрелая тектоника
невозможна. Прямые legacy API остаются прежними; новый мост их не вызывает
и не устанавливает глобальную блокировку старых сценариев.

## Один сохранённый сценарий

Команда (новый выходной каталог обязателен):

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1 \
/workspace/habitable-moon-venv/bin/python -m analysis.genesis_transfer_bridge.run_saved \
  --output /workspace/genesis-transfer-bridge-01
```

[Машинный отчёт](result.json) фиксирует все входные и программные хеши.
Принятое начальное состояние — 0,8684 Myr, 800 когорт; существующий непринятый
half2 используется **только как поставщик неизменной fixed-cut геометрии**.
Его конечное состояние не передаётся и не становится принятой историей.
Каждый solid cut связан с исходной когортой по ID, грани, массе и q-интервалу.

Результат: DATA_BRIDGE_VERIFIED_PHYSICAL_HANDOFF_BLOCKED; 0 новых шагов;
0,894 с; пакет 40 425 683 байта до записи краткого scenario.json.
Полная масса 2,0316747196205566e24 kg, энтальпия 4,3833079785138317e30 J;
обе невязки группировки 0. Остаток вращательной проекции скорости
0,999999886 исходной RMS. Сохранена упругая энергия 3,44416071573364e19 J.
Максимальные ошибки реконструкции strain0/strain1 равны
2,54e−20 / 1,69e−21; точные исходные байты также сохранены.

Тесты проверяют баланс/реконструкцию, нулевую скорость, порчу идентичностей,
часов и значений, побайтовую сохранность CRLF, запрет перезаписи, неверный pin,
изменение производного пакета даже с обновлённым хешем и запрет обхода допуска.

Итог: **33 теста PASS за 2,33 с** — новый мост, прежняя проекция и
`test_genesis_mature.py`, включая чтение через v131 без создания новой геологии.
Первый запуск последнего набора остановился на отсутствующем matplotlib;
после установки проектных зависимостей matplotlib 3.11.2 и Pillow 12.3.0
из PyPI в изолированное окружение весь адресный набор прошёл. Численные
зависимости и requirements-файлы не изменялись.

## Следующий сквозной тест — конечный объём работы

Следующий результат должен соединить этот пакет с **одним существующим
Starter continuation**: сначала сопоставить его активные поля и тепловые
резервуары с контрактом, затем выполнить один ограниченный save/load smoke-test
на уже пригодном сохранённом Starter checkpoint. Он должен подтвердить
сохранение времени, материальных запасов и истории слабости через существующий
runner. Контрольный текущий Genesis-пакет обязан по-прежнему получать отказ.
Это проверит пригодную приближённую ветвь, но не легализует перенос текущих
800 когорт. Для него отдельно необходимо физически обосновать эволюцию или
пренебрежимость сохранённых остаточных полей; простого копирования недостаточно.

Новая серия Genesis, навязанный раскол, континенты из одной толщины, изменение
канонической истории и публикация в эту работу не входят. Четыре пространственных
контроля и первый из шести подробных этапов остаются открытыми. Restore CLOSED.

# Адресная диагностика перед новым выбором направления

База: `0fa57a9c45df464491fcb551d27e147cdfdc8ffd`.
Новых адаптивных прогонов **0**, радиальных вычислений для этой диагностики
**0**. Полный малый набор и четыре больших контроля не запускались.
Критерий 2e−6, порядки 3/5, коэффициент 8 и лимиты сохранены.

## Что говорят сохранённые результаты

Максимальное отношение embedded-оценки к допуску:

| Пример | Четыре дочерние ячейки [0,U] | Смешанные на всех | Смешанные на родителе | Только 5×5 |
|---|---:|---:|---:|---:|
| Полушар | 793 | 1537 | 752 | 671 |
| Малый полушар | 760 | 1492 | 753 | 665 |
| Касание | 130 | 168 | 98,8 | 127 |

У варианта 5×5 три крупнейшие ячейки дают соответственно 25,0%, 24,3%
и 22,7% оценки худшей стороны. Для 80% нужны **13, 14, 14 ячеек**.
Вклад распределён между всеми тремя треугольниками (28–37% на каждый).
Даже идеальное устранение ошибки трёх крупнейших ячеек при неизменном
остальном оставляет **503, 503, 98 допусков**. Одной локальной поправки мало.

Координаты трёх крупнейших ячеек; номер треугольника начинается с нуля:

| Пример | Треугольник | s | t | Доля оценки худшей стороны |
|---|---:|---|---|---:|
| Полушар | 1 | [1/2,1] | [1/2,3/4] | 9,30% |
| Полушар | 0 | [0,1/2] | [1/4,1/2] | 7,86% |
| Полушар | 2 | [0,1/2] | [1/2,3/4] | 7,86% |
| Малый | 1 | [1/2,3/4] | [1/4,1/2] | 9,19% |
| Малый | 2 | [1/4,1/2] | [0,1/2] | 7,57% |
| Малый | 0 | [1/4,1/2] | [1/2,1] | 7,57% |
| Касание | 2 | [0,1/4] | [1/2,3/4] | 7,75% |
| Касание | 2 | [1/2,3/4] | [3/4,1] | 7,50% |
| Касание | 0 | [1/2,3/4] | [0,1/4] | 7,50% |

На прежней четырёхчастной сетке смешанные правила связывают **95,4%,
95,2%, 99,7%** наблюдаемой ошибки с ячейками, где преобладает t.
98,2%/98,6% суммы t-индикатора полушаров приходится на широкий участок
`domain_start -> Gamma_sphere_resultant`; у касания — на
`domain_start -> Delta`. Это не потеря массы в узких корневых полосах.
Эти направления измерены на прежней сетке: переносить их автоматически
на новые конечные ячейки нельзя. Например, новые верхние ячейки малого
полушара уже выбирают t, и ещё один индикатор не обязан изменить их выбор.

Сопоставление **одинаковых родителей** даёт более сильное свидетельство.
Для касания, треугольник 0, s=[1/2,1], t=[1/2,1], вариант 5×5 выбирал s,
а оба смешанных варианта — t. Сумма наблюдаемых ошибок двух детей после
s в **31,896 раза** больше, чем после t. Симметричный родитель треугольника
2 даёт тот же результат. Другие несовпадающие решения дают отношения
1,33–13,72; встречается и обратная ошибка выбора (t вместо s).
Дочерние суммы восстановлены независимо из разностей последовательных
глобальных оценок с добавлением ошибки родителя; для нового варианта
они сверены с явно сохранёнными дочерними суммами. Это сравнение фактических
разностей 3/5, не истинных ошибок интеграла. На полушарах среди общих
родителей различий выбранной оси не найдено: там различаются доступные
глубина и число ячеек, а не подтверждённый лучший выбор на одном родителе.

## Проверка остатка интерполяции

`residual.py` принимает **готовые** значения одной и той же плотности с
якобианом на сетках 5×5 и 3×3. Интерполяция степени четыре и остаток
вычисляются рационально; радиального вычислителя в модуле нет. Остаток
разложен на среднее, центрированные маргинальные компоненты s/t и
взаимодействие. Это диагностические величины, не новая граница ошибки.

Адресные тесты подтверждают:

- В `s⁴ + 10⁻⁴ t⁸` ложный вклад s исчезает, остаётся t.
- Произведение квадратов расстояний до fine-узлов, невидимое на 5×5,
  обнаруживается coarse-узлами; направление однозначно для функции одной оси.
- Для тензорного полинома степени четыре остаток точно нулевой.
- Взвешенная сумма остатка равна прежней Q33−Q55 для идеальных правил:
  Gauss-3 точно интегрирует интерполянт степени четыре. Для буквальных
  двоичных узлов/весов в тесте расхождение менее 1e−14. Поэтому одна сумма
  остатка не даёт нового независимого свидетельства ошибки.
- Ненулевой неотрицательный полином, исчезающий на объединении узлов
  обоих правил, остаётся невидимым. Остаток также не сертификат точности.

**Проверка на физических ячейках заблокирована отсутствием nodal-данных.**
Предыдущие процессы сохраняли суммы правил, параметры лучей, ошибки и
историю делений, но словарь `samples` и массивы значений сеток оставались
только в памяти. Снимки исходников не являются снимками этих массивов.
Даже смешанные суммы не определяют 34 значения сеток. Геометрию узлов
можно восстановить, значения плотности — только вычислить повторно.
Прежнее предложение проверить индикатор по сохранённым данным без новых
вызовов было неполным; этот отчёт явно исправляет его. Утверждения, что
остаток уже исправляет выбор на настоящей сфере, **нет**.

## Решение о продолжении и измеримая цена

Доказательства принципиальной недостаточности фиксированного порядка или
лимита **нет**. Контрпримеры для произвольных функций не доказывают
невозможность на данной сфере. Измеренная разница 31,896 оставляет
проверяемую возможность улучшить выбор; распределённая ошибка одновременно
не позволяет обещать, что этого хватит для допуска. Повышать лимит по
необоснованной экстраполяции или перебирать новые стратегии не следует.

Для решения пользователя доступны два конкретных варианта:

1. Сохранить абсолютный запрет новых радиальных вызовов: остановиться
   на этом диагнозе. Физический остаток и стратегия остаются непроверенными.
2. Разрешить один адресный повтор для указанного плохого родителя касания:
   **34 обращения сеток, 33 уникальных радиальных вычисления / 66 скалярных
   вызовов сторон**, без адаптивного прогона. Цена восстановлена по сохранённой
   геометрии и буквальным узлам, см. `target.json`. Сохранить интервалы
   значений в файле; проверить, выбирает ли остаток t, сопоставив с уже
   известными обоими дочерними результатами. Если нет — остановить гипотезу.
   Если да — это лишь основание для следующей ограниченной адресной проверки,
   не разрешение считать полный набор успешным. Девять крупнейших ячеек
   таблицы потребовали бы не более 510 обращений (до учёта совпадений).

Ни один из этих повторов сейчас не выполнен: действует требование
«без новых радиальных вызовов». Увеличение порядка/лимита не предлагается
как установленное решение, поскольку его необходимость и цена сходимости
пока не доказаны.

## Проверки и файлы

**120 тестов PASS** (7 новых + 113 регрессионных), 17,47 с. Регрессионные
тесты выполняют свои существующие небольшие проверки вычислителей;
нулевая стоимость относится к новой диагностике и новым экспериментам.
Независимый аудит заново проверил точное покрытие 107 конечных ячеек,
полный учёт [0,U] и исторические 3366/3366/3399 вызовов без обращения к
радиальному вычислителю. Прежний аудит 525 лучей и 819 корней сохраняется.
Неопределённость корней по-прежнему менее 0,025% допуска.

`summary.json` содержит локализацию, сравнения одинаковых родителей и SHA256
15 прочитанных отчётов; `independent_audit.json` — независимые проверки.

```sh
python -m pytest -q tests/test_genesis_volume_interpolation_residual.py
```

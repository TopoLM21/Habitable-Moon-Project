**PASS: замкнутый малый расчёт + миграция настоящего состояния + restart.**
Новый opt-in модуль `tectonics/genesis_reservoir_thermal.py` не подключён к

## Реализованное поведение

`CoupledThermalState` содержит непересекающиеся материальные резервуары,
их массу, энтальпию и общий reference ledger. Материальные состояния —
силикат и вода; механические elastic/kinetic банки имеют нулевую материальную
массу, поскольку это другие формы энергии того же материала.

`conduct(state, edges, dt_seconds)` выполняет действительный обмен:
`Qab = dt * Gab * (Ta-Tb)`, `Gab` в Вт/К. Одна величина Q одновременно
вычитается у донора и добавляется получателю. Температуры всех резервуаров
изменяются: заданного бесконечного горячего/холодного источника нет.
Явный CFL `dt ΣG ≤ m cp_min` ограничивает шаг; слишком большой шаг отвергается,
а не стабилизируется искусственным теплом. Это FV-обмен по прежнему закону
Fourier (`MobileModel._conduct`); реальные геометрические Gab пока не подключены.
В manufactured-тесте Gab — явно заданные параметры контрольной задачи.

Энтальпия силикатов `cp*T + L*melt_fraction(T)` взята из `genesis.py`;
водная часть — прежние sensible/vapor terms `surface_enthalpy`, без rock term.
Изменение доли расплава уже оплачено энтальпией. Новая масса/добавочная latent
heat при затвердевании не создаётся. Тест реально охлаждает колонку,
уменьшает melt fraction и нагревает поверхность. Новый cohort birth adapter
ещё не вызывается; нельзя объявлять этим тестом проверку полной birth-history.
Вода ниже 273,16 К отвергается: ice вне прежнего уравнения состояния.

`mechanical_exchange` поддерживает локализованный Maxwell-перенос из банка
`elastic:column:i:j` в ту же `column:i:j`; произвольный другой столбец
отвергается. В замкнутом тесте энергия релаксации получена из точного закона
`U(t)=U0 exp(-2γt)` с явно фиксированным γ. Реальный BE constitutive solver
этим не заменяется и к новым температурам ещё не подключён.
Отдельный режим numerical уменьшает механический запас и увеличивает только
диагностический sink. Drag, damage и thermal-work routing пока отвергаются,
а не получают произвольные доли. Это ограниченный работающий primitive,
не заявление о полном механическом coupling.

## Миграция: явный консервативный выбор

Сохранённые global energy и column profiles раньше не были взаимно согласованным
разложением. Принята инженерная проекция: сохранить глобальную суммарную
тепловую энергию, все массы/профили колонок и прежнюю водную энтальпию.
Остаточная масса и энергия назначаются **новой глубокой мантии**:

`Mdeep = Msilicate − ΣMcolumns`

`Edeep = Eglobal(mantle+surface) − ΣEcolumns − Ewater(surface)`.

Неположительный остаток останавливает миграцию. Surface rock теперь входит
в силикатные колонки, отдельного повторного surface-rock резервуара нет.
Это выбор представления: однородная остаточная глубокая мантия. Он не
восстанавливает неизвестное распределение старого тепла и не доказывает
геометрическую точность коры. Core-state не выдумывается.

На реальном принятом 0,8684 Myr checkpoint:

- 2560 column-layer резервуаров + глубокая мантия + поверхностная вода;
- Msilicate = 2,030548e24 кг, Mcolumns = 4,215118e22 кг;
- суммарная тепловая энергия 4,3833079785138317e30 Дж сохранена;
- все массы и энтальпии колонок сохранены;
- новая Tdeep = **1645,272559 К**, прежняя Tmantle = **1654,184285 К**;
- разность deep-vs-old-mantle энергии −1,216208e29 Дж включает смену
  принадлежности массы и представления; **это не физический поток**.

Изменение температуры явно записано в provenance. Проекция остаётся отдельным
кандидатом, canonical checkpoint не заменён. Упругая память, когортная история,
старые журналы и механическое состояние остаются в неизменном legacy-файле,
на который новый state ссылается точным SHA. Load мигрированного state требует
исходный файл с этим SHA; без него загрузка отвергается. Реальное механическое
состояние пока не прикрепляется к новому runtime (явный `not_attached`).

Формат `genesis-coupled-thermal-0.1`, sealed JSON; уникальные владельцы масс,
положительные материальные массы, неотрицательная энергия, постоянные суммы
водной/силикатной массы, `ΣE + numerical_sink = reference_total`.
`historical_opening_balance=null`; новые counters относятся только к
`since_reference_state_only`, а не к неизвестному прошлому.

Проверены замкнутый обмен/фазовый переход, знаки парных записей, локальная
релаксация, отсутствие numerical heating, CFL/overdraw/duplicate-edge отказ,
неизменность входного состояния при отказе, legacy SHA, seal и побайтовый
restart. Миграция настоящего checkpoint: **0,849 с / ≈152 МиБ**, новых шагов
реальной планеты **0**. `summary.json` содержит SHA и путь результата

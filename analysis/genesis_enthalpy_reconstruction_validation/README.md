# Консервативная реконструкция энтальпии: ложное retirement не применяется

**PASS реконструкции, BLOCKED_SUBCELL_RESOLUTION для механического входа.**
Новый модуль `genesis_enthalpy_reconstruction.py` восстанавливает удельную
энтальпию постоянной внутри каждой FV-ячейки (P0). Это минимальное по порядку
представление, не пытающееся восстановить неизвестную форму профиля из средних.
41 тест PASS; реальный 80-face случай читается из сохранённых endpoints,
без нового thermal step. Canonical/default и mechanical state не изменяются.

## Что исправлено

Единственный энергетический источник истины — `E_cell`, с весом `m_cell`.
Внутри ячейки `h=E/m`; на частичном q-интервале берётся точная доля массы
этой ячейки и та же доля E. q — материальная **массовая** координата, не
равномерная координата физического радиуса. При прежней постоянной rho объём
равен m/rho; конические объёмные веса не заменяются длинами отрезков.
Поддерживаются неравные массы ячеек; границы q строятся по накопленной массе.

Полная энергия каждой ячейки воспроизводится точно. Значение h не выходит
за её mean, поэтому положительность и локальный максимум-принцип выполняются
без ограничителя/новых коэффициентов. Из h инвертируется **прежний** фазовый
закон cp*T+L*phi(T). Представительная P0 phase fraction не объявляется
однозначно известной истинной средней фазой произвольного скрытого профиля.

Граничная температура используется для теплового потока и диагностики
связности; она больше не заменяет энергетический профиль ячейки линейной T
между границей и её центром. Поэтому прежнего искусственного +4,224e19 Дж
нагрева полосы нет: P0-представление следует охлаждающимся сохранённым mean.
Latent heat повторно не добавляется, новый activation threshold не вводится.

## Фаза, solidus и связность — разные выходы

- **Представительная фаза:** получена из h_cell по существующему закону.
- **Solidus threshold:** прежнее `h_s=cp*Tsolidus`; новая доля активации не задана.
- **Connected front:** не подставляется равным скачку P0. Хранятся внешние
  границы допустимого положения, а не ложная subcell-точка.

Если mean ячейки выше h_s, вся эта ячейка не может быть полностью твёрдой:
первый связанный полностью твёрдый фронт находится не глубже её дальней границы.
Но mean ниже h_s не исключает скрытых горячих включений. Из одних средних
положительную нижнюю границу непрерывной связности доказать нельзя, поэтому
консервативная нижняя граница q=0. Если сама поверхность горячее solidus,
связность с поверхностью нулевая — это **не** доказательство плавления нижней массы.

Это enclosure возможных положений по данным, не вероятностный доверительный
интервал. P0 как численная реконструкция определён однозначно, но его скачки
не получают статус физически разрешённого фронта.

## Реальные сохранённые 80 граней

На каждой грани первая ячейка имеет mean выше h_s. И before, и after дают
`q_front ∈ [0; 0,03125]`. Принятые фронты около 0,00170…0,00174 лежат внутри
обоих интервалов. Их сдвиг порядка 7e−6 по этим средним не разрешён.
Ячейка соответствует 1/32 колонной массы (1250 м исходной 40-км координаты,
а не автоматически той же деформированной физической толщине).

Все первые ячейки охлаждаются: максимальная Δh равна −207,056 Дж/кг.
Для 800 принятых когорт сохранены буквальные ID/q-интервалы и SHA памяти;
для каждой записана before/after энтальпия как **подмножество** column energy.
Это не новый резервуар. Каждый столбец разбит на неперекрывающиеся старые
live-интервалы и их дополнение, чтобы не потерять и не посчитать массу дважды.

- максимальная относительная ошибка разбиения массы: 0;
- энтальпии: 1,8792e−16;
- все 800 ID и прежняя память сохранены;
- применённых retirements: 0;
- физическая масса remelt: **unknown/null**, а не утверждение «плавления нет»;
- mechanical input: **null**, guard не допускает переименование readiness.

Предыдущий `genesis_reservoir_birth.prepare` остаётся историческим кандидатом
по legacy T-front и не является разрешением механического перехода. Новый
консервативный view не принимает его диагностические retirement-интервалы
как физическое удаление. Энерго-ошибка T-реконструкции устранена в новом view,
но неопределённость настоящего subcell-профиля не скрыта.

## Что нужно для корректного механического входа

Теперь технический блокер конкретен: **нет консервативного начального
подъячеечного h-профиля/дополнительных степеней свободы у поверхности**, которые
одновременно согласуются с cell integrals и принятой историей тонких твёрдых
когорт. Среднее первой ячейки уже двухфазно, хотя часть её материала была
активирована по прежнему интерполированному solidus. Подставить всем старым
когортам температуру центра означало бы искусственно переинициализировать
их термомеханическую историю; поэтому это запрещено.

Минимальный следующий работающий результат — ограниченная реконструкция
верхней ячейки с точным E_cell, явно сохранённой subcell-информацией/интервалами
и проверкой совместимости с accepted material bounds. Если данных недостаточно,
требуется выбранная и зафиксированная консервативная инициализация этих новых
степеней свободы; это не восстановленная точная история. До этого нельзя
выдавать точный birth/remelt или экспортировать K/U. Mixed/isolated solid
допуск не заменять произвольным solid-fraction порогом.

## Проверки и воспроизведение

Тесты: heating/cooling, проход через обе фазовые границы, unequal-mass/volume
weights, arbitrary interval partitions, положительность/max principle,
неподвижность mean при изменении boundary, hot-cap connectivity без плавления
нижней массы, guard. Saved real case сохранён в
`/workspace/genesis-enthalpy-reconstruction-02/view.json`; pins и числа —
`summary.json`. Команда только читает endpoints:

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1 \
/workspace/habitable-moon-venv/bin/python -m analysis.genesis_enthalpy_reconstruction_validation.run \
  --output /workspace/genesis-enthalpy-reconstruction-NEW
```

Исходный isolated thermal test имел отключённые external sources и +14,6749%
нижнего оттока после migration. Это не прежний прогноз и не допуск пространственной
сходимости коры. Принятые данные, численная диссипация и физические распределения
heat/drag/damage этим изменением не затронуты.

# Один завершённый пространственный контроль intact-оператора

**PASS:** вся матрица жёсткости 18×18 неразрезанного конического элемента
сопоставлена с независимым интегралом в физических координатах. Максимальная
нормированная ошибка матрицы 3,513e−15 при заранее выбранном критерии 1e−11;
максимальная ошибка энергии шести аффинных деформаций 1,508e−14.
Контроль: 192 узла, 0,035 с, пик RSS 46 796 KiB. 71 адресный тест PASS,
включая отрицательные проверки. Production-код не менялся.

## Почему четыре старых контроля не блокируют intact

По сохранённому `genesis_volume_operand_validation/evidence/actual_control/control_report.json`
и `genesis_volume_precision_validation/summary.json`:

| Контроль | Когорта / грань | Радиус источника | Область |
|---|---|---|---|
| 0 | 1 / 0 | 100 м | локальный шар и банки Γ |
| 1 | 1 / 0 | 4,024215510221975 м | локальный шар и банки Γ |
| 2 | 41 / 40 | 100 м | локальный шар и банки Γ |
| 3 | 80 / 79 | 100 м | локальный шар и банки Γ |

Это интегралы будущей локальной вставки/освобождения разлома: полные, W15 и
пробные тензоры над ограниченными областями источника и сторонами Γ. Все
четыре остаются OPEN по угловой точности, их старые 1992 failed components
не переоценены. Они нужны при использовании этих региональных/sharp-interface
операторов, а не как универсальный допуск каждого шага связной модели.

Проверенная цепочка вызовов текущего BE:
`analysis/genesis_be_candidate/adapter.py:trial` → `VolumeModel._assembly` →
`assemble_updated_volume_operator` → `_construct_operator`.
Здесь интегрируются целые неразрезанные когорты; интегратор локального шара
и банков Γ не вызывается. Gate по-прежнему запрещает переход к активному
разлому. Угловой контроль sharp-interface не заменяет этот gate.

## Что именно проверено

Три manufactured элемента: толстый слой; повёрнутый косой треугольник;
планетный масштаб с относительной толщиной 1e−9. E=60 ГПа, ν=0,25 — параметры
контрольного материала, не изменение источника Genesis.
Используется настоящая `_construct_operator` с manufactured геометрией;
фабричная проверка источника не обходится для реального состояния.

Oracle отдельно дифференцирует отображения
`x=λ ΣN X`, `u=ΣN[A+(λ−1)P]` через физический Jacobian и интегрирует
`λ_L tr(ε_i)tr(ε_j)+2μ ε_i:ε_j`. Он не использует production B, матрицу C,
радиальные моменты или три штатных угловых узла. Для полного uncut-элемента
Jacobian пропорционален λ²; после умножения мерой интегранд квадратичен по λ
и угловым координатам. После Duffy степень не выше 3 по первой координате
и 2 по второй: правило 4×4×4 достаточно аналитически, остаётся округление.

PASS требует ошибок ≤1e−11 для полной матрицы (норма Фробениуса), объёма,
симметрии, шести жёстких движений и энергий шести аффинных деформаций.
FAIL возвращает ненулевой код процесса. Отрицательные тесты отдельно
выключают радиальную дисперсию и заменяют три угловых узла центром — оба
повреждения обнаружены по полной матрице, хотя affine patch может их пропустить.

Нормовый критерий не является относительным допуском каждой малой компоненты.
Контроль не доказывает сходимость сетки, нелинейную пространственную точность
планеты, полный mass/drag оператор или глобальный тепловой баланс.

## Пользовательский результат и следующий шаг

Доступен быстрый воспроизводимый контроль пространственного ядра, используемого
BE и midpoint. Для ограниченной intact-работы не требуется повторять четыре
старых sharp-interface sweeps. BE50 остаётся инженерным кандидатом, BE25 —
контролем; этот тест не меняет ранее установленные временные ограничения.

Следующий конечный результат для intact: **карта глобального энергетического
журнала на уже сохранённых BE50 данных**, без новой эволюции. Подготовленный
scope: сопоставить тепловые запасы/граничные потоки с термомеханической работой,
physical sinks и отдельными numerical sinks; для каждого члена указать поле,
единицы, знак и наличие обратной связи. PASS карты означает полноту инвентаря,
а не замкнутость физического баланса: отсутствующий обмен фиксируется как
конкретный блокер, не дополняется выдуманным теплом. Входы — сохранённый корень
и `/workspace/genesis-be-time-control-01/50/step_{1,2}.json`; бюджет до 60 с /
1 GiB, без solve, sweep или редактирования checkpoints. Этот следующий аудит
здесь не выполнялся. Активация разломов всё ещё требует собственного допуска.

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1 \
/workspace/habitable-moon-venv/bin/python -m analysis.genesis_uncut_spatial_control.run \
  --output /workspace/genesis-uncut-spatial-control-NEW.json
```

Результат и pins: `summary.json`. Новый путь обязателен, существующие файлы
не перезаписываются. Никаких шагов Genesis, архивных восстановлений или push.

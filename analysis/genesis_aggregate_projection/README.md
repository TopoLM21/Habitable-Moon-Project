# Выбранное физическое сокращение Genesis → ранний тектонический режим

**Результат этого хода — конкретное физическое решение и проверенная
мгновенная проекция, НЕ активный адаптер и НЕ допуск новой эволюции.**
Причина выбора установлена измерением: обычный Starter одновременно меняет
тепловую фазовую структуру, память напряжений и закон прочности. Исправить
это одним присваиванием его старых переменных нельзя.

Рекомендован один вариант: **среднее напряжение + первый момент по толщине,
тепловые ячейки с раздельным твёрдым материалом, существующее узловое движение**.
Не требуется точная динамика каждой когорты. Оригинальные когорты остаются
исходными доказательствами; их архив не объявляется активной памятью.

## Измерения одного текущего состояния

Закреплённый старт 0,8684 Myr / 800 когорт; новые временные шаги **0**.
`preflight.py` завершился за **1,375 с**; [отчёт](result.json) содержит входные
SHA256, все 80 результантов/моментов и тепловую проекцию. Существующий half2
использован только для fixed-cut геометрии, не как новое принятое состояние.

| Проекция | Измеренный результат |
|---|---|
| Только среднее напряжение | Отбрасывает 19,13% упругой энергии |
| Среднее + первый момент по толщине | Отбрасывает 7,399%; сохраняет 3,1893e19 J из 3,4442e19 J |
| Остаточная упругая энергия | 2,5484e18 J; отдельный механический остаток, НЕ тепло |
| Изменение собранного вектора внутренних сил | 0,1181% по общей L2-норме обобщённых сил |
| Проверка энергии независимой квадратурой | Отличие от сохранённой энергии 2,38e−16 относительно |
| Энергетическое разложение «проекция + остаток» | Невязка 5,95e−16 относительно |
| Один общий тепловой столбец из 32 слоёв | Температурная RMS-ошибка 9,981 K; масса ниже солидуса становится **нулевой** |
| Раздельные ячейки face/layer/solid-or-other | 2640 вместо 3360; RMS-ошибка 0,2517 K; сохраняются 7,2619e19 kg ниже солидуса |
| Последняя тепловая группировка | Невязки полной массы и энтальпии 0 в этом измерении |

Глобальная малая ошибка сил не ограничивает локальную ошибку силы или времени
события. 7,399% энергии не объявляются допустимыми безусловно. Общий столбец
отвергается объективно: исчезает уже существующая твёрдая оболочка.
Сохранение массы ниже солидуса в этом состоянии не доказывает правильность
всех последующих фазовых событий. Ячейки `other` могут содержать частичный
расплав; метка solid — исходная идентичность материала, не новый порог.

## Точная спецификация рекомендуемого сокращения

Для каждой исходной грани используем её исходную систему координат,
объёмные веса и физическую координату z по нормали. Сначала центрируем z
относительно центра объёма. Проекция упругой деформации:

    e_bar(z) = a + b (z-z_c)
    ∫ (e-e_bar) dV = 0
    ∫ (z-z_c)(e-e_bar) dV = 0

На текущей грани C одинаков для когорт: E, nu и damage относятся к грани.
Поэтому это также ортогональная проекция по упругой энергии C. Храним полные
шесть компонент a и b, не один `cooling_stress_pa`. Сохраняются обобщённые
результанты N=∫σdV/A и моменты B=∫(z-z_c)σdV/A, включая поперечные компоненты.
Точно сохраняется виртуальная работа для любой виртуальной деформации,
постоянной или линейной по z на этой грани. Это **не** утверждение сохранения
каждой контактной силы или локального изгиба: угловая неоднородность и более
высокие моды утрачиваются, поэтому отдельно измерен полный исходный вектор сил.
При C, меняющемся внутри грани, нужна C-взвешенная проекция; текущая формула
не должна автоматически применяться к такому материалу.

**Активный закон для следующей реализации:** проецировать существующее
Maxwell-уравнение на базис phi=(1,z-z_c), а не вводить новую вязкость:

    G_ab = ∫ phi_a phi_b dV
    R_ab = ∫ phi_a phi_b / tau(T) dV
    G c_dot = ∫ phi (B_volume v - thermal_strain_rate) dV - R c

Здесь tau(T)=eta(T)/E берётся из исходных параметров, температуры — из
сохранённых тепловых групп. Это выбранное приближение Галёркина: обратное
воздействие отброшенного r на релаксацию, ∫phi r/tau(T)dV, опускается и должно
отчётно оцениваться. При постоянном tau и принятом базисе эта связь нулевая;
при разных температурах она вообще не нулевая. Изменение C, рождение,
переплавление и движение границ требуют прежних энергетических членов;
они не исчезают из-за проекции. На этом ходе новый закон не интегрировался.

**Импульс:** оставить существующие 252 обобщённые узловые скорости и их
согласованную матрицу массы. Они малы по сравнению с когортной памятью и
не требуют превращать одно тело в rigid plate. Начальные P, L, K и все
узловые скорости при таком переносе неизменны. В активном варианте сохраняется
исходный баланс импульса с внешней тягой; внутренние силы собираются тем же
оператором B_volume из сокращённых напряжений. Starter используется для
организации ранней топологии, но его `_fit_domain_motion` нельзя применять
как замену уравнению импульса. После разделения этот баланс также нельзя
заменить ненаблюдаемым обнулением общего вращения.

**Тепло:** использовать существующие энтальпию/инверсию температуры и потоки,
объединяя только соседние cut-cells одной грани, исходного слоя и статуса
solid/other. Масса M=sum(m), энтальпия H=sum(H), h=H/M. Оставить глубокий
резервуар и воду отдельно. Тепло между группами переносить одним парным
потоком с противоположными знаками; не включать эти же H вторично в глобальный
резервуар Starter. Его обычный reference-column является пассивным механическим
оценщиком и не может стать вторым источником энергии. Граница живого твёрдого
материала и история рождения сохраняются явно; новый материал не получает
усреднённый возраст старых когорт.

**Энергетический остаток:** U_source=U_reduced+U_residual. В активной
механической энергии учитывается U_reduced, в отдельном механическом резерве —
U_residual. Не прибавлять полный U_source ещё раз и не переводить U_residual
в тепло при передаче. Для первого ограниченного режима рекомендован явно
замороженный резерв без работы/нагрева; это допущение, не активная Maxwell-память.
Оно допустимо только на горизонте, где оценены возможные релаксация и обмен
остатка с разрешёнными модами. Продолжение, которому нужен этот обмен,
должно остановиться либо получить дополнительную остаточную моду; молчаливого
списания энергии не допускается. Длительное физическое затухание остатка этим
решением не моделируется.

## Прочность и повреждение: не переносить настройки незаметно

[Сравнение](strength_comparison.json) использует **одно и то же текущее
конститутивное напряжение**; приливная фазовая добавка, сдвиг и сглаживание
в сравнении числа превышений не включены.

- Genesis: 12 MPa × водное ослабление. В текущем состоянии вода в этом законе
  не снижает предел: 12 MPa на всех гранях. Превышений растяжения 22.
- Starter добавляет неоднородность прочности 15%, горячий множитель вплоть
  до 0,5 и множитель (1−0,5 damage). При текущих температурах/повреждениях
  получилось 5,199–6,665 MPa и 40 превышений. Это изменение физической модели.
- Замена полного тензора изотропным скаляром при прежних 12 MPa даёт только
  6 превышений; относительная потеря тензора по Frobenius-норме 48,09%.
- E=60 GPa, nu=0,25, остаточная жёсткость 0,02, базовая прочность 12 MPa,
  damage time 0,01 Myr, healing 100/0,01 Myr совпадают по исходным значениям.
  Совпадение чисел не означает совпадения законов: Genesis ослабляет приливную
  жёсткость через damage, Starter имеет иной драйвер растяжения/сдвига.
- Genesis требует persistence 0,05 Myr для активации; обычное Starter-разделение
  использует пороговую eligibility. Нельзя терять текущий возраст кандидата.
  Радиус сглаживания тоже различается: Genesis 800 km, Starter 300 km.
- **50 kPa — базальная тяга исторического опыта, не прочность горячей корки.**
  Рекомендуется сохранить исходные 20 kPa, исходный закон повреждения и память
  persistence. Порог разлома 0,65 не повышается и не снижается ради результата.

Нельзя одновременно сохранить inherited σ и вновь добавить к нему полное
Starter `mantle_tensor*scale + cooling_stress`: это двойной учёт начальной
нагрузки. Начальное σ задаётся только проекцией; последующие приращения и
внешняя работа приходят из существующего исходного оператора.

## Объективный допуск качественного режима

Не вводился произвольный процент «достаточно хорошо». Следующая короткая
проверка выбранного сокращения должна контролировать одновременно: исходные
массу/H/P/L и полный энергетический баланс с резервом; существующую твёрдую
массу/фазовый фронт; знак и запас до исходных порогов разрушения с учётом ошибки
напряжения; ошибку виртуальной работы и вклад отброшенной релаксации за весь
выбранный интервал. Если граница ошибки пересекает порог события, событие
нельзя сертифицировать по одному среднему. Проверяются также локальные, а не
только глобальные нормы. Измеренные здесь малые ошибки сил — основание выбрать
вариант для такого конечного опыта, не допуск произвольной долгой эволюции.

Четыре synthetic cases PASS: rigid движение/P/L, uniform thermal/M/H,
uniform stress/результанты и момент, nonrigid/энергетический остаток и виртуальная
работа. Тесты выполняются за 0,11 с. Модель/legacy/default/canonical не изменены;
активный Starter checkpoint не создан, физических шагов не было. Следующая
реализация имеет конкретную цель: подключить указанные G/R и тепловые группы
к прежнему короткому coupled-step, сохранив узловой импульсный оператор и
исходный закон повреждения, затем проверить один интервал. Новая полная
тектоническая система для этого не предлагается.

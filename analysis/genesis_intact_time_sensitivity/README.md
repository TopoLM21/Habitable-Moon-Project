# Ограниченная чувствительность intact-продолжения: 100 / 50 / 25 лет

База разработки `ca650a399c73ab231d1b8ed5a27ab8e0793f12be`.
Один и тот же принятый родитель 0,8684 млн лет / 800 когорт; конечное время
всех ветвей 0,8685 млн лет. Результат 1×100 лет берётся из закреплённого
предыдущего PASS-контроля. Только ветви 2×50 и 4×25 вычисляются заново.
Каноническая история не продвигается; физика и допуски не изменяются.

## Результат: обе новые ветви PASS, временной error bound не получен

Все шесть новых шагов прошли штатные и независимые проверки. Оба restart
побайтово совпали. В каждой ветви все 80 граней остаются без активных плоскостей
и кандидатов gate. Конечные каталоги: **880 / 960 / 1120 когорт** для
100 / 50 / 25 лет соответственно. Исходные **800 IDs, owner/material и
интервалы q** сохранены точно; общий исходный mass-chart и reference mesh
совпадают. Принятые байты 0,8684 млн лет неизменны.

### Почему совпадение конечной кинетической энергии недостаточно

| Общее время | Ветвь 50 лет | Ветвь 25 лет |
|---|---:|---:|
| 0,86845 млн лет | 5046,581059 Дж | 5071,563178 Дж |
| 0,8685 млн лет | 5128,114948 Дж | 5128,115041 Дж |

В середине того же интервала расхождение **24,982119 Дж**, тогда как на конце
оно меньше 0,0001 Дж. Поэтому совпадение концов нельзя считать доказательством
сходимости скоростей или непрерывной траектории. Формула существующей схемы
`v_after=2·increment/dt−v_before` делает проверку зависимости от чётности
подшагов необходимым следующим диагностическим вопросом. **Причина ещё не
установлена**: материал рождается, меняются коэффициенты и тепловой драйвер;
ни чистый артефакт чётности, ни физическое колебание здесь не доказаны.

### Проверки, стоимость и следующий технический шаг

Максимум независимой относительной невязки дискретного баланса по шести
новым шагам — **1,192·10⁻¹²**, координатного импульса — **1,865·10⁻¹⁴**.
Проверены predictor, обновление воды/повреждения/persistence, память, масса,
энергия и геометрия всего интервала каждого шага. Все gates закрыты;
максимальный damage на конце: 0,03976425 / 0,03981678 / 0,03984336.
Все исходные проверки и допуски сохранены; новая временная норма не введена.

Общее время **491,320 с**, пик RSS **782292 КиБ ≈764 МиБ**. Каталог результатов
`/workspace/genesis-intact-time-sensitivity-01/` занимает около **231,49 МБ**.
Все лимиты соблюдены. Ни 100-летний baseline, ни новые ветви не заменяют
принятый checkpoint. Побайтовая проверка исходных артефактов и повторное
построение сравнений выполнены отдельным `summarize.py` без model.step.

Конкретный следующий шаг для intact-драйвера: по уже сохранённым шести шагам
разложить кинетическое различие на **общую старую массу**, рождение новой
массы, среднюю скорость increment/dt и знакопеременную часть endpoint-скорости.
Проверить их работу с базальным сопротивлением и импульсом. Для этого не
нужны новый fracture law, новые симуляции или ещё более мелкая серия. Такой
аудит определит, что нужно исправлять/контролировать в интеграторе прежде,
чем выбирать производственный dt по почти совпавшим конечным энергиям.

Блокеров выполненного сравнения нет. Блокеры заявления о временном допуске:
меняющаяся дискретизация рождения/памяти, чувствительность промежуточной
кинетики и отсутствие независимой оценки глобальной временной ошибки.
Пространственная сходимость также не проверялась этим экспериментом.

## Проверка смысла разбиения до запуска

`genesis_volume_thermal._advance_core` на каждом endpoint обновляет глобальную
тепловую/орбитальную историю, теплопроводность колонок по текущим верхним
площадям и положение фронта. Внешние параметры источников одинаковы, но
частота их численного обновления меняется. Это не три запуска с намеренно
одинаковой заранее предписанной тепловой траекторией.

`genesis_bulk_birth.advance_bulk_birth` создаёт отдельную когорту для каждого
нового интервала material-q, возникшего за принятый шаг. Когорты имеют
одинаковую модельную температуру рождения solidus=1400 K, но разные интервалы
рождения и последующие температуры. `genesis_volume_loading` устанавливает
Maxwell ratio=0 для вновь рождённого материала; старые когорты получают
релаксацию по температуре endpoint. Поэтому дробление меняет и дискретизацию
времени/теплового сопряжения, и разбиение/возраст новой памяти материала.

**Это проверка наблюдаемой чувствительности связанного алгоритма, не чистая
временная сходимость при неизменной материальной дискретизации.** Нельзя
сравнивать новую cohort 801 между ветвями как один и тот же кусок вещества.
Различие числа когорт не является само по себе нарушением сохранения массы.

## Сопоставимые величины

Сохраняются и сравниваются:

- масса всего живого и нового материала, масса по всем 80 граням, границы
  live-q; отдельно общая и неперекрытая масса между ветвями;
- температуры и коэффициенты памяти **только исходных 800 когорт**;
- A-перемещения и скорости общей верхней сетки, отдельно P-коэффициенты
  аффинной радиальной кинематики (P — не отдельное физическое перемещение);
- конечные средние растягивающие напряжения всех граней и damage всех граней;
- конечные упругая и кинетическая энергии, приращения работы/диссипации
  относительно одного родителя, тепловые поступления и отвод;
- энтальпии колонок и координаты глобального теплового состояния. Последние
  нормированы на 10¹² Дж/м² по `genesis.ENERGY_SCALE`, а не измеряются в Дж.

`symmetric_relative_max = max|a−b| / max(max|a|,max|b|)` — описательная
нормировка без scale floor; при двух нулевых массивах результат нулевой.
Она не является допуском. Сравнение коэффициентов strain0/strain1 отдельно
не заменяет сравнения полного физического поля с учётом их компенсации.

Каждый шаг использует прежний `VolumeSlipModel`, штатные проверки и
независимый `audit_actual_interval`; каждый endpoint ветви получает
независимый аудит энергии и полный restart. Gate проверяется на всех 80
гранях до/после шага: появление кандидата прекращает контроль. Gc/T/k/kc
не назначаются. Restart доказывает воспроизводимость, не сходимость по dt.

## Заранее ограниченный бюджет

Оценка по предыдущему контролю: 16,35 с на новый шаг и около 17 с на аудит
интервала, плюс чтение родителя и два restart — примерно 6–9 минут.
Общий предел 720 с, внешний watchdog 740 с; шаг ≤90 с, аудит шага ≤90 с,
загрузка/restart ≤180 с с учётом остатка общего бюджета. Адресное пространство
≤4 ГиБ, свободный диск ≥1 ГиБ. При отказе — запись диагностики и остановка,
без повторных попыток или изменения допусков.

**91 тест PASS**: прежние 86 gate-тестов, инвариант массы при дроблении
новорождённого материала, отказы при gaps/overlaps, несовпадении размеров
наблюдаемых и конечного времени, корректная обработка нулевых величин.

Воспроизведение только в новом каталоге, проектный Python:

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1 python -m pytest -q -p no:cacheprovider tests/test_genesis_intact_time_sensitivity.py tests/test_genesis_connected_step.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1 timeout 740 python -m analysis.genesis_intact_time_sensitivity.run --output /workspace/NEW-intact-time
OPENBLAS_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1 python -m analysis.genesis_intact_time_sensitivity.summarize --input /workspace/NEW-intact-time --output /workspace/NEW-intact-time-summary.json
```

Численные результаты, остановки, времена стадий и SHA всех артефактов
фиксируются в `summary.json`. Полные состояния остаются в отдельном локальном
каталоге. Тепломеханический резервуар, fracture/contact и sharp proof при
исходном 2e−6 остаются отдельными открытыми условиями плана.

## Один выбранный метод

На **том же прямоугольнике** строятся точные тензорные коэффициенты Бернштейна
сферы Q, Γ и плотности K. Плотность имеет степень (8,8,8), 729 коэффициентов.
Коэффициенты источника развёрнуты из прежнего арифметического графа; никакой
новой подгонки по узлам нет. Граф → источник остаётся тем же явно описанным
алгебраическим контрактом, а не новым независимым физическим выводом.

Для положительного базиса B_i с интегралом V/n:

- `I = V/n sum(b_i)` — точный интеграл K по целому блоку;
- `L = V/n sum(min(b_i,0)) <= integral_A K <= V/n sum(max(b_i,0)) = U`
  для любой измеримой части A блока;
- `integral |K| <= U-L`.

Знак и отсечение определяются совместно по Q и Γ на этом же блоке:

- доказанно вне сферы — [0,0];
- внутри сферы при фиксированном Γ — точная работа `±I/2`;
- неизвестная часть сферы при фиксированном Γ — `[L/2,U/2]` либо
  `[-U/2,-L/2]`;
- неизвестный Γ — `[-(U-L)/2,+(U-L)/2]`, с сохранением маски сферы.

Отрицательные вклады не теряются. Здесь учитываются оба геометрических
ограничения и интеграл плотности, но корреляция знака K с Γ в пересечённых
блоках ещё не разрешена: именно это ограничивает следующий результат.
Плоскость Γ нулевой объёмной меры не создаёт двойного учёта.

## Независимость, покрытие и стоимость

Региональный аудитор не использует de Casteljau или экспериментальный
преобразователь. Он восстанавливает корневые полиномы обратным преобразованием,
затем рассчитывает детей отдельной замкнутой биномиальной формулой. Проверяет
хеш каждого набора коэффициентов, точное покрытие родителя двумя детьми,
отсутствие потерянных/повторных листьев, каждое включение, все промежуточные
суммы и сохранение интеграла K при каждом делении. Внешнее покрытие всей
сферы/когорты проверяется независимым Cramer-аудитором. Неопределённые куски
не отбрасываются. Это проверка данного скалярного интеграла, не всех тензоров.

Контроллер: 3 корневых преобразования и 2592 парных ограничения полиномов
(864 деления × 3 полинома), 1729 блоков. Аудитор рассчитывает 5184 отдельных
дочерних ограничения. Его время учитывается отдельно в `summary.json`.
Радиальных интегралов, механических решений, новых разбиений исходного дерева — 0.

10 адресных тестов PASS: точные интегралы и компенсация, отрицательная плотность
на границе сферы, совместное пересечение сферы/Γ с аналитическим интегралом
5/64, сохранение работы при делении, тождества обоих методов ограничения,
отказ при подмене коэффициентов/границ/хеша и тождественно нулевом Γ.
Полные локальные сертификаты и исходники закреплены SHA256 в `summary.json`.

## Воспроизведение

Из корня репозитория, проектным Python, с `OPENBLAS_NUM_THREADS=1`,
`OMP_NUM_THREADS=1`, `PYTHONDONTWRITEBYTECODE=1`:

```sh
python -m pytest -q -p no:cacheprovider tests/test_genesis_regional_moments.py
python -m analysis.genesis_regional_moment_validation.pilot --output /workspace/NEW-pilot.json
python -m analysis.genesis_regional_moment_validation.regional --output /workspace/NEW-region.json
python -m analysis.genesis_regional_moment_validation.regional_audit --input /workspace/NEW-region.json --output /workspace/NEW-audit.json
```

Скрипты отказываются перезаписывать существующий результат до вычислений.
Это команды воспроизведения, не автоматическое разрешение следующего опыта.
Вход — сохранённый центрированный сертификат предыдущего прохода. Остановка
по времени на другой машине может дать другое число блоков; для проверки
именно принятого результата аудировать сохранённый сертификат с закреплённым
SHA256. Все его точные границы и дерево воспроизводятся без повторного поиска.

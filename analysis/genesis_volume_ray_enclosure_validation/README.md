# Строгие включения вкладов интервалов корней

Разработка поверх `9c0f2d3cf964f1237c10f274d66810c5e4e87d72`.
Все три аналитических примера теперь проходят сравнение с точным объёмом
при **2e−6**, но **общий embedded-критерий по-прежнему не проходит**.
Четыре больших тензорных контроля не запускались; основной тензорный
интегратор не изменён. Прежний лучевой эксперимент сохранён отдельно.

## Что изменено и что строго ограничено

Вместо квадратуры узких интервалов корней учитывается их интегральное
включение **[0,U]**. Они не объявляются пустыми. Представителем вклада
служит середина включения, а вся неопределённость оплачивается из прежнего
бюджета ошибок coarse/fine. Допуск не увеличивается; исходная функция
`_strict_allowance(2e-6, coarse, fine)` и направленное суммирование сохранены.

Реализация отказывает для геометрии вне проверенной аналитической семьи:
X=((0,0,10),(4,0,10),(0,4,10)), A=P=0, центр шара (1,1,9), R≤1/4,
lambda∈[literal 0.8,1], нормаль Γ=(0,0,1). Это **не универсальное
включение тензорных компонент**. Строго ограничен вклад интервалов корней,
а не весь угловой интеграл с его ещё неизвестным остатком квадратуры.

Предыдущее доказательство даёт
`rho_max=25R/[2(9−R)]`, максимальный вклад волокна `32R` и не более
17 корней событий с кратностями. У каждого непустого интервала изоляции
`width≤lo·2⁻⁴⁰`. Суммарный вклад интервалов корней ограничен
`U=32R·17·rho_max²·2⁻⁴⁰`, равномерно по внешнему параметру t.

Для ячейки `[s0,s1]×[t0,t1]` треугольника удвоенной площади J используется

`U_cell=U·J·(t1−t0)·[f(s1)−f(s0)]`, где `f(s)=2s−s²`.

Это следует из `rho≤rho_max`, границы ширины интервала и интегрирования
производной f. При разбиении на четыре дочерние ячейки сумма U_cell
сохраняется точно. Поэтому включение не теряется и не дублируется при
адаптации. Вклад каждого банка получает свою границу. При касании Γ
пустая сторона доказывается точным условием `offset≥9+R`; нулевые выборки
для такого вывода не используются.

Каждая coarse/fine квадратура получает включение [0,U_cell] и его середину.
Направленные оценки расстояния до представителя учитывают также округление
середины и суммирования. Сумма ошибок обеих квадратур не меньше U_cell;
это проверяется и в ходе расчёта, и независимым аудитором. Включение не
используется как добавка к допуску или как искусственный нижний масштаб.

## Проверки строгости и покрытия

**100 тестов PASS**: 9 новых и 91 прежний. Сохранены проверки касаний,
нескольких пересечений, положительных интервалов шириной 2⁻¹⁰⁰, корней
около границ, точного разбиения и 46 реальных узких Γ-областей.
Новые отрицательные тесты отклоняют неоплаченную неопределённость,
заниженную границу вклада и добавление неопределённости к допуску.

Независимый аудит заново выводит U из геометрии, не вызывая функцию
рабочей границы. Проверены **497 записанных лучей, 763 корня, 2982
выборочных нулевых волокна и 147 конечных ячеек**. В число лучей входят
подготовленные лучи следующего уточнения, не поместившегося в лимит.
Аудитор проверяет корни квадратной формулой, ширины их интервалов,
сохранение всех вкладов, отсутствие перекрытий прямоугольников параметров,
покрытие каждого треугольника и оплату границ в каждом шаге адаптации.
Для сериализованных long double величин применяется один наружный шаг
binary64; точные геометрические границы хранятся рационально.

## Результаты и сравнение

Порядки **(3,5)**, множитель embedded-разности **8**, лимиты **3400
радиальных вычислений / 2000 ячеек / глубина 24** не изменены.
Ошибки ниже относительные; для нулевого объёма — абсолютные.

| Пример | Прежние ошибки − / + | Новые ошибки − / + | Узлы прежде → теперь | Истинные объёмы |
|---|---|---|---|---|
| Полушар | 3,384e−6 / 2,922e−5 | **1,481e−6 / 1,449e−6** | 3128 → 3196 | PASS |
| Малый полушар | 3,132e−6 / 2,933e−5 | **9,840e−7 / 9,519e−7** | 3128 → 3196 | PASS |
| Касание Γ | 7,580e−8 / 0 | **2,609e−8 / 0** | 3196 → 3366 | PASS |

Вычисления на интервалах корней: **1564/1564/1598 → 0/0/0**; их вклад
полностью сохранён интервально. Освободившийся бюджет потрачен на уточнение
остальной области: конечных ячеек **18/18/36 → 36/36/75**.
Новые скалярные замеры — 3,61/3,71/4,05 с, включая изоляцию корней
0,94/1,11/1,09 с. Ускорение по времени не заявляется: выполнено больше
уточнений, замеры не являются оценкой стоимости тензорного интегратора.

**Общий критерий остаётся OPEN во всех трёх случаях.**

| Пример | source/root ошибка / допуск − / + | embedded-разность / допуск − / + |
|---|---|---|
| Полушар | 0,000241 / 0,000241 | **792,7 / 630,8** |
| Малый полушар | 0,000228 / 0,000228 | **759,9 / 616,6** |
| Касание Γ | 0,000121 / 0 | **129,9 / 0** |

Неопределённость корней укладывается в бюджет; она не является текущим
блокером. Блокер — `8·Σ|I5−I3|` на участках без корней. Хорошее совпадение
fine-результата с известным объёмом не позволяет отбросить этот критерий.
Следующее четырёхчастное уточнение не помещается в прежний лимит.
Новый результат четырёх исходных тензорных областей не вычислялся;
их прежние 1992 нарушения на область не переоценены.

## Следующий точный шаг

Проверить раздельные ошибки по внутреннему s и внешнему t на ячейках
с наибольшей ошибкой, используя смешанные правила 3×5 и 5×3. Стоимость
этих диагностик должна входить в тот же лимит. Затем проверить выбор
направления деления вместо безусловного создания четырёх дочерних ячеек.
Это следующая **непроверенная гипотеза**, а не уже полученная сходимость.
Порядки, коэффициент 8 и допуск не ослаблять. Для перехода к общей модели
по-прежнему нужны компонентные границы тензоров и безопасное суммирование
компенсирующихся вкладов. Большие контроли до прохождения адресного
критерия не обоснованы.

# Точные пересечения Γ: локальное исправление, сферическая сходимость OPEN

Разработка поверх `1db6753b5da920ccf333248b772f339a17bc48ea`.
Точное аффинное пересечение использует рациональное `a/(a-b)` без
округления параметра ребра. Обе стороны разреза сохраняются; узел лежит
точно на событии. Исходный округлённый эксперимент сохранён отдельно.

Новый приоритет — максимальная ошибка относительно собственного допуска
компоненты. Верхняя граница непросэмплированного объёма остаётся в ошибке,
но сам факт пропуска больше не имеет безусловного приоритета. Нулевой
допуск при ненулевой ошибке по-прежнему даёт бесконечный приоритет.
Условия допуска, бюджет исходной неопределённости и лимиты не ослаблены.

## Проверенный результат

- **24 теста PASS**, включая 46 реальных положительных областей,
  недостижимых после прежнего округлённого разреза. Теперь в каждой есть
  положительный узел исходного правила Гаусса порядка 5. Проверены точная
  площадь, отсутствие перекрытий и выравнивание по двум событиям Γ/когорта.
- **47 существующих регрессионных тестов PASS** для границ банков, покрытия
  source-области и разбиения; вместе с новыми проверками — **71 PASS**.
- Приоритет проверен на конфликте малого непросэмплированного объёма и
  большой тензорной ошибки, нулевом допуске и смене единиц компонент.
- Экспериментальные сферические разрезы и сглаживание **отключены по
  умолчанию**. Их сохранение площади не обеспечило точность интегрирования.
  Экспериментальный код и все прежние результаты сохранены.

Независимый read-only аудит трёх уже выполненных проб: **271 ячейка,
796 проверок пересечений, 2168 проверок радиальных сечений** — без потери
площади или положительных перекрытий. Истинный объём полушара вычислен
через другую рациональную формулу для π; учтено округление JSON-сумм.
Новая квадратура при этом не запускалась.

| Сохранённая проба | Узлы | Относительная ошибка − | Относительная ошибка + | Неопределённые ячейки |
|---|---:|---:|---:|---:|
| Обычное midpoint-разбиение | 3332 | 0,00195724 | 0,000863002 | 0 |
| Midpoint со сглаживанием | 3400 | 0,00330430 | 0,00340083 | 0 |
| Сферические разрезы по длинному ребру | 3400 | 0,000607958 | 0,00620228 | 8 |
| Те же разрезы со сглаживанием | 3400 | 0,00678939 | 0,00544665 | 4 |

Исходный допуск — **0,000002**. Ни одна проба его не достигла.
Погрешности в таблице — относительные числа, не проценты.
Первые пробы с параллельным разрезом и выбором корня у конца ребра также
сохранены в `/workspace/genesis-exact-events-sphere-*`; этот аудит
ограничен тремя указанными вариантами после них.

Четыре больших тензорных контроля в этом шаге **не повторялись**:
сферическая стратегия не прошла аналитический контроль. Последний
сопоставимый результат остаётся **1992 нарушения на каждую область**;
новое число нарушений для точного Γ-разреза пока неизвестно.
Локальный PASS 46 областей не заменяет этот расчёт и не допускает физику.

## Воспроизведение

Из корня репозитория с установленными проектными зависимостями:

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -m pytest -q \
  tests/test_genesis_volume_exact_event_mesh.py \
  tests/test_genesis_volume_sphere_event_mesh.py

python -m analysis.genesis_volume_exact_events_validation.audit_sphere_trials \
  --reports /workspace/genesis-exact-events-sphere-midpoint-smoothed-01/report.json \
  /workspace/genesis-exact-events-sphere-balanced-native-01/report.json \
  /workspace/genesis-exact-events-sphere-balanced-smoothed-01/report.json \
  --output /workspace/genesis-exact-events-sphere-independent-audit-NEW.json
```

Выход аудитора должен быть новым файлом. Он не запускает интегрирование.
CLI `sphere_oracle` по умолчанию использует точные Γ-разрезы, исправленный
приоритет и обычное midpoint-уточнение. Отклонённые эксперименты включаются
явно флагами `--sphere-events` и/или `--smoothing`; повторять их без новой
гипотезы не нужно. Старые отчёты не являются прогонами новых настроек
по умолчанию. Хеши отчётов, кода и минимальной фикстуры — в
`summary.json`; подробный независимый аудит — в `sphere_trial_audit.json`.

## Следующий обоснованный шаг

Проверить интегрирование по лучам Duffy с изоляцией корней событий сферы,
когорт и Γ и явными положительными областями каждой стороны Γ. Это новая
гипотеза, ещё не реализованная. До больших контролей нужны доказательство
покрытия вдоль каждого луча, обработка касаний и интервалов корней без
потери узких областей, сохранение source-бюджетов при компенсации вкладов
сторон, затем полушар и 46 реальных областей при прежних лимитах.

Строгий угловой остаток и ошибка идеальных параметров Гаусса остаются
открыты. История 0,8684 млн лет / 800 когорт / четыре интервала не
продвинута. Первый этап и физический допуск остаются OPEN.

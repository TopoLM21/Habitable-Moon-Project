# Эксперимент с интегрированием по лучам Duffy

Разработка поверх `97d600756c589f3bbdb4ff1e160f8869d073f35c`.
Гипотеза дала заметное локальное улучшение, но **не прошла весь аналитический
контроль при 2e−6**. В основной тензорный интегратор она не включена;
четыре больших контроля не запускались. Их последний результат остаётся
1992 нарушения на область, новое число неизвестно.

## Алгоритм и доказанный охват

Полный исходный симплекс разбит на три треугольника с общим центром
`(4/9,5/18,5/18)`. Этот центр выбран для аналитических примеров; общий
алгоритм выбора центра деформированного источника здесь не заявляется.
Независимое точное пересечение треугольников проверяет площадь и перекрытия.

Для каждого внешнего параметра `t` используется луч
`N(rho,t)=a+rho*((1-t)b+t*c-a)`. Все N, веса и якобианы вычисляются
рационально из прежних бинарных параметров Гаусса порядков 3 и 5.
На луч ограничиваются события A, дискриминант сферы, оба пересечения
с границами когорты, g, оба Γ/когорта и Γ/сфера. Их степени не выше четырёх.

Точное square-free разложение и последовательность Штурма находят все
различные корни, включая корни чётной кратности. Концевые корни учитываются
отдельно. Каждый непустой интервал изоляции содержит один корень; соседний
точный корень не может остаться на его границе. Ширина ограничена расстоянием
до края области и масштабом отделения корня. Неудача при лимите глубины
даёт отказ, а не пустую область.

Объединение перекрывающихся интервалов разных событий образует упорядоченную
границу разбиения [0,1]. Соседние интервалы стыкуются точно; сумма длин равна
единице. Поэтому нет пропусков или перекрытий положительной меры. Отдельные
точные корни имеют нулевую меру и остаются в записи. Интервалы вокруг корней
**все интегрируются**, даже если нулевые выборки могли бы выглядеть пустыми.
На промежутке без корней знак существования положительной части постоянен:
изменение возможно только при одном из перечисленных событий. Только если
обе стороны имеют нулевой вклад, промежуток исключается из квадратуры.
Тождественно нулевые полиномы не объявляются отсутствующими событиями;
неразрешённая целая линия на Γ и вырожденная линия дают отказ.

В каждом оставленном промежутке применяется точная замена
`rho=lo+(hi-lo)*(2*s-s²)` с соответствующим якобианом. Уточнение делит
прямоугольник параметров s,t на четыре части. Прежний критерий собственного
допуска и направленное агрегирование исходных ошибок переиспользуются
непосредственно из существующего контроллера. Поправки к допуску нет.

## Адресные проверки

**91 тест PASS**: 20 новых и 71 прежняя регрессия, включая 46 узких Γ-областей.
Новые проверки охватывают касание, четыре корня, корни на границах, положительный
интервал шириной `2⁻¹⁰⁰`, близость к краю `2⁻¹²⁰`, отказ при исчерпании лимита,
реальные сферические события и отрицательные тесты независимого аудитора.

Отдельный аудитор не использует ни Штурма, ни подстановку полиномов рабочего
кода: коэффициенты сверяются с прямой геометрией, корни — с квадратной
формулой и целочисленными границами квадратного корня. Для этих аналитических
примеров события на лучах имеют степень не выше двух; большую степень
аудитор отклоняет. Проверены **315 записанных лучей, 497 корней и 1890
выборочных нулевых радиальных вкладов**. В число лучей входят также
подготовленные лучи следующего уточнения, которое не поместилось в лимит.
Это не независимый аудит всех возможных деформированных источников.

## Точность и стоимость

Лимиты неизменны: **3400 радиальных вычислений, 2000 ячеек, глубина 24**;
каждое радиальное вычисление включает обе стороны Γ. В таблице ошибки
относительные; для точно нулевого объёма указана абсолютная ошибка.

| Пример | Радиус | Узлы | Ошибка − | Ошибка + | Сравнение с точным объёмом |
|---|---:|---:|---:|---:|---|
| Полушар | 0,25 | 3128 | 3,38432e−6 | 2,92188e−5 | FAIL |
| Малый полушар | 2⁻¹² | 3128 | 3,13200e−6 | 2,93329e−5 | FAIL |
| Γ касается шара | 0,25 | 3196 | 7,58012e−8 | 0 | PASS только истинных объёмов |

Объёмы сравниваются с рациональными границами π и точной формулой
`2πR³/3` для полушара или `4πR³/3` для полного шара. Включение шара в конус
и исходный интервал lambda проверено точными неравенствами. При касании
Γ нулевая сторона остаётся нулевой. **Embedded-критерий всё ещё не проходит
во всех трёх примерах**, в том числе у касания; общий допуск не получен.

Для того же полушара прежнее midpoint-разбиение дало ошибки
`0,00195724 / 0,000863002` на 3332 узлах. Новый вариант улучшает их примерно
в **578 / 30 раз**, используя 3128 узлов. Замер новых скалярных экспериментов:
2,6–3,0 с, из них 0,57–0,83 с на изоляцию корней. Это не сравнение времени
полного тензорного вычислителя: прежнего сопоставимого замера времени нет.

Половина узлов — **1564/3128** для каждого полушара и **1598/3196** для
касания — потрачена на узкие интервалы вокруг корней. Следующее четырёхчастное
уточнение не помещается в лимит. Это измеренная причина расхода бюджета,
а не доказательство, что её устранение автоматически обеспечит сходимость.

## Следующий обоснованный вариант

Для данной семьи примеров можно строго ограничить **суммарный истинный
вклад** всех интервалов корней, равномерно по t. Это ещё не используется
в интеграторе и не является границей его текущей квадратурной ошибки.

Пусть R≤1/4. На физическом шаре lambda≥(9−R)/10, поэтому каждое отклонение
N1,N2 от центра не больше `25R/[9(9−R)]`. На любом ребре симплекса
максимум модулей двух компонент направления луча не меньше 2/9.
Следовательно, физический вклад возможен только при
`rho≤rho_max=25R/[2(9−R)]`.

Длина сферического радиального отрезка lambda не больше `2R/10`,
det(X)=160 и lambda≤1, поэтому вклад одного волокна не больше `32R`.
Сумма степеней событий не больше 17. Каждый интервал корня, пересекающий
физическую область, имеет ширину не больше `rho_max*2⁻⁴⁰`; якобиан Duffy
содержит множитель rho≤rho_max, а сумма удвоенных площадей треугольников — 1.
Получается верхняя граница

`U = 32R * 17 * rho_max² * 2⁻⁴⁰`.

Она составляет менее **1e−9 объёма полушара**, в том числе при очень малом R.
Функция `fixture_root_box_mass_bound` и три теста закрепляют формулу.
Это ограничение относится только к описанным аналитическим примерам.

Следующий эксперимент: заменить квадратуру **только этих интервалов**
строгим интегральным включением и оплатить всю его ширину из неизменного
бюджета ошибки. Не объявлять интервалы пустыми и не терять положительную
область. Затем повторить скалярные проверки в прежнем лимите. Для общего
тензорного интегратора потребуются отдельные границы каждой компоненты и
безопасное суммирование компенсирующихся вкладов сторон. Лишь после этого
обоснованы четыре исходных контроля и их независимый аудит.

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -m pytest -q \
  tests/test_genesis_volume_ray_roots.py \
  tests/test_genesis_volume_ray_geometry.py \
  tests/test_genesis_volume_ray_audit.py

python -m analysis.genesis_volume_ray_validation.experiment \
  --case half_ball --output /workspace/genesis-ray-half-ball-NEW
python -m analysis.genesis_volume_ray_validation.experiment \
  --case small_half_ball --output /workspace/genesis-ray-small-half-ball-NEW
python -m analysis.genesis_volume_ray_validation.experiment \
  --case tangent_Gamma --output /workspace/genesis-ray-tangent-Gamma-NEW

python -m analysis.genesis_volume_ray_validation.audit \
  --runs /workspace/genesis-ray-half-ball-NEW \
  /workspace/genesis-ray-small-half-ball-NEW /workspace/genesis-ray-tangent-Gamma-NEW \
  --output /workspace/genesis-ray-audit-NEW.json
```

Все выходные пути должны быть новыми. `summary.json` закрепляет реальные
прогоны02, исходники и записи лучей; небольшие отчёты и независимый аудит
включены сюда. Пробы01 сохранены: после них сравнительный контроллер был
согласован с исходным max-based допуском и направленным суммированием;
финальные объёмы и число узлов в02 не изменились.

Точные Γ-разрезы остаются в рабочем варианте. Ранее отклонённые стратегии
отключены. История, физика и допуск не изменены; этап 1 и общая угловая
сходимость остаются OPEN. Новая эволюция и публикация не выполнялись.

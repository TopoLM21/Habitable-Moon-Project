# Объёмный вектор Kpa·a для W15-моды №1: включения получены, знаки открыты

База: `63b96868fac7803e81c660bd1d446a5b91b475cd`. Одна вычислительная серия
для текущей области **100 м**, cohort 1 / face 0, прежнего центра, материала и
буквального `a=W15[:,0]·2⁻¹³ м`. История, источник и поверхность не изменены.
Старые локальные блоки 4,0242 м и приближённые угловые компоненты не использованы.

Получены полные signed-включения **18 компонент b=Kpa·a**. Все 18 включают
ноль: знаки и относительная точность 2e−6 **не разрешены**. Независимый аудит
подтвердил включения и точное тождество взаимной работы. Это результат для
упругого объёмного действия на фиксированную виртуальную пробу, не связанная
Maxwell-касательная J, не движение, не устойчивость и не высвобождение энергии.

## Постановка до расчёта

`b_i = ∫Ω B_iᵀ C (G a) dV`, i=0,…,17. B имеет размерность м⁻¹, a — м,
Ga — безразмерная деформация, C — Па, dV — м³; **b — Н**.
В представленном графе Bhat=λB и Ghat=λG/H; множитель λ² объёмной меры
сокращается с двумя знаменателями. Интегрируется полином
`det(X) Bhat_iᵀ C Ghat_a · H` по dN1 dN2 dλ, внутри сферы и исходной когорты.
H=±1/2; Γ имеет нулевой объём. Сохраняется прежний контракт буквальных
представленных коэффициентов источника, без нормализации замороженных данных.

Нужны **18 плотностей одного действия**, а не 18×18 локальная или 252×15
глобальная матрица. Вычисляются один six-component Ghat_a и родительские
функции Bhat. Глобальное отображение в 252 координаты:
`[0,1,2,3,4,5,72,73,74,75,76,77,84,85,86,87,88,89]`.
Остальные 234 строки именно этого локального действия равны нулю по опоре
добавленной функции в выбранной когорте. Это не обнуление неизвестных
блоков связанной механики. Остальные 14 W15-мод не освобождались.

Для взаимной работы заранее задана только диагностическая родительская проба
`q_i=(-1)^i/[8192(i+1)] м`, вне 18 выбранных координат q=0.
Она не объявляется принятым приращением. Сравниваются:

- свёртка 18 полных включений qᵀb, в Дж;
- отдельно собранная скалярная плотность `(Ga)ᵀ Cᵀ (Bq)` с интегрированием
  по всей той же области, в Дж.

Необходимы одинаковые область, мера, H и симметричный C. Аудитор проверил
**18 глобальных полиномиальных тождеств** между плотностями прямого действия
и независимо свёрнутыми родительскими коэффициентами; отдельно проверено
тождество смешанной работы. Это доказательство по коэффициентам, не по
совпадению нескольких точек. Три проверки исходной коэффициентной алгеброй
дополнительно подтвердили 54 значения компонент плотности.

797 вычислений графа (корень и листья), 120 секунд до перехода на корневые
огибающие для оставшихся листьев; внешний timeout процесса 180 секунд.

## Разрешённость конкретных наблюдаемых

С округлением наружу:

- qᵀb из компонент: **[−30,721; +30,637] Дж**;
- отдельный сопряжённый интеграл: **[−8,516; +8,432] Дж**;
- пересечение этих включений совпадает с более узким вторым интервалом;
- **дефект тождества взаимной работы: точно [0;0] Дж**.

Последний результат разрешает алгебраическую взаимность. Он не означает,
что величина работы, её знак, компоненты сил или общий допуск 2e−6 разрешены.
Интервальные середины не объявляются точными значениями.

Отрицательные части сохранены. Из 14 328 пар «лист/компонента» 1764 имеют
доказанное нулевое включение, остальные 12 564 включают оба знака; строго
положительных/отрицательных локальных включений нет. Это свойство ширины
огибающих первой серии, не утверждение о нулевых реальных силах.

Измеримый барьер — зависимость повторяющихся переменных в интервальном
графе, помимо неопределённости границ. Для сопряжённой работы ширина 16,9473 Дж;
даже на 233 листьях с ранее доказанными внутренностью и фиксированным Γ
вклад в ширину составляет 5,6952 Дж. На 150 листьях, ранее доказанных внешними
более сильным методом Бернштейна, текущая грубая геометрическая огибающая
оставляет лишние 1,4625 Дж ширины. Здесь прежние классификации используются
только для разбора стоимости неопределённости, не для сужения результата.
Бесконечный перебор не запущен; лимит 797 вычислений исчерпан.

Дальнейшее сужение требует отдельного ограниченного шага: перенести на эти
18 полиномиальных плотностей уже существующие интегральные огибающие
Бернштейна/моментов и использовать проверенные геометрические классификации.
Это кандидат следующего метода, не обещание достижения 2e−6 и не разрешение
автоматически запускать новую серию.

**Выбранного источником поверхностного закона по-прежнему нет** — физический
блокер остаётся. Связанный баланс не решался; этап 1 и четыре больших
пространственных контроля остаются открытыми.

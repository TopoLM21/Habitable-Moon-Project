# Проверки связанного эксперимента

`tests/test_fractional_coupling.py`: **19 выполнений прошли**, отдельный контроль завершился за 6,80 с. Эти проверки добавляются к собственным тестам дробного переноса, теплового модуля и базальных моментов; перекрывающиеся запуски не следует складывать.

| Проверка | Независимый критерий |
|---|---|
| Единственный владелец тепла | Полный конечный тепловой контекст равен прямому `StarterLoadingModel.advance`; входной источник не меняется; дополнительный тепловой сток равен нулю. |
| Перезапуск | Состояние, полный архив снятых порций и история совпадают; через публичный интерфейс совпадает SHA-256 всей контрольной точки. |
| Материальные балансы | Суммы непосредственно по сохранившимся и снятым порциям сверяются с независимыми рождениями и подписанными тепловыми изменениями четырёх величин. |
| Ограниченный запас мантии | Рождение коры отклоняется при исчерпании опорного резерва; исходное состояние остаётся прежним. |
| История отдельных материалов | Возраст, владелец, происхождение и повреждения не усредняются при динамическом переносе. |
| Необычная температуропроводность | Явно заданный коэффициент меняет передачу нагрузки молодой части смешанной ячейки, сохраняя примордиальный материал и глобальное тепло. |
| Формат и целостность | Загрузчик отклоняет файл только переноса, иной источник, испорченные данные и даже заново хешированный файл с потерянным архивом порций. |
| Транзакции и публикация | Невалидный шаг, несогласованные часы и остановка тепла не меняют состояние; ошибка на втором шаге не создаёт частичный результат; существующие файлы сохраняются. |

Примечание: в очень молодом Starter холодный слой может целиком лежать внутри химической коры. Поэтому тест температуропроводности проверяет изменение базальной нагрузки, а не требует появления холодной мантии там, где её ещё физически нет.

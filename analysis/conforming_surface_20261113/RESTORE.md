## Read and verify without continuing the calculation

From the repository root, using the project Python environment:

```bash
.venv/bin/python - <<'PY'
from pathlib import Path
import hashlib, json
from tectonics.conforming_surface import ConformingSurface
stage = Path('analysis/conforming_surface_20261113')
manifest = json.loads((stage / 'artifact_manifest.json').read_text())
for path, entry in manifest['artifact_files'].items():
    data = Path(path).read_bytes()
    assert len(data) == entry['bytes'], path
    assert hashlib.sha256(data).hexdigest() == entry['sha256'], path
for path, expected in manifest['runtime_files_sha256'].items():
    assert hashlib.sha256(Path(path).read_bytes()).hexdigest() == expected, path
surface = ConformingSurface.load(stage / 'states/native100_fresh')
print(surface.budget())
other = ConformingSurface.load(stage / 'states/native_resume100')
assert surface.checkpoint() == other.checkpoint()
print('Artifacts and complete restart state verified.')
PY
```

does not reconstruct past stress, repair old overlap or recompute source stocks.

## Reproduce under a new name

`verify.py` refuses to overwrite existing results and saved states. Its named
batch commands are the original parameter definitions, not commands to rerun
over this preserved directory. To make an independent native control, import
the harness and supply an unused name:

```bash
.venv/bin/python - <<'PY'
import importlib.util
from pathlib import Path
path = Path('analysis/conforming_surface_20261113/verify.py')
spec = importlib.util.spec_from_file_location('shared_surface_check', path)
checks = importlib.util.module_from_spec(spec)
spec.loader.exec_module(checks)
checks.run('independent_native100', scenario='native', end=100., adaptive=True)
PY
```

For an actual checkpoint continuation, use `ConformingSurface.load()` and
`advance(absolute_target_myr)`, then save to a new directory. The regression
comparison resumes `states/native50` at its recorded **50.75 Myr** and advances
to 100 Myr. Choosing a different stopping time changes step subdivision and
need not reproduce bitwise results, although its physical error must converge.
Do not continue `prescribed_native20` as valid unconstrained mechanics: it
stopped at 9.198486 Myr at the declared column-height applicability limit.

Smooth and oblique controls share a fixed fine reference field and conservative
aggregation. Native grid controls prolong the same protected 320-cell initial
material inventory. They do not regenerate different random initial data.
All coefficient values, accuracy controls and actual achieved times are in
the case JSON files. For the fresh-process timing, use the recorded scope in
`fresh_process_resources.json`; per-case wall times are not full application
timings.

The summarized CSV and figures are generated by `summarize.py`; it also refuses
to overwrite its JSON products. Preserve the current evidence before creating
new output. No old artifacts, archives or histories need to be removed.

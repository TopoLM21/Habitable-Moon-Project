# Общие нерегулярные плиты: установлен геометрический блокер

13.10.2026, `feat/simplified-genesis`, основа `1fb078a640bfa5596a3d30edb703ad5cbbd291a5`.
Restore CLOSED. Это продолжение одобренного контакта без трения, не новая физика.

**Цель ненулевого относительного движения произвольных доменов не достигнута.**
Для проверенного нерегулярного разбиения её запрещает геометрия текущей модели,
а не величина шага или отсутствие алгоритма поиска столкновений. Поэтому новый
event solver, якобы решающий этот случай дроблением, не добавлен.

## Почему дробление не помогает

1. Жёсткие домены вращаются вокруг фиксированного центра и сохраняют площадь.
   Их суммарная площадь равна площади сферы. Непересечение поэтому означает
   полное покрытие; открытие положительной площади требует перекрытия где-либо
   ещё. Разрешить «пустоты» только в детекторе контакта недостаточно.
2. На общей дуге большой окружности с нормалью n скорость нормального зазора
   равна `(ω_b − ω_a)·(x × n)`. Она неотрицательна при непроникновении.
   Суммарный поток через все границы равен нулю по сохранению площадей;
   следовательно, скорость зазора на каждой дуге равна нулю.
3. Значения в двух разных концах дуги вынуждают `ω_b − ω_a` быть параллельным n.
   Две общие дуги с непараллельными нормалями вынуждают `ω_b = ω_a`.
   Связный граф таких пар оставляет только общее вращение.
4. Это также локальное ограничение конечных непрерывных движений: при малом
   смещении внутренние участки двух исходных дуг остаются смежными. Для полного
   покрытия их плоскости должны совпадать. Две непараллельные плоскости не
   допускают близкого к единичному относительного вращения. Нельзя обойти
   ограничение движением с нулевой начальной скоростью или уменьшением шага.

`packing_rigidity` выдаёт достаточный сертификат этого случая: пары владельцев,
номера концов двух дуг и ненулевое векторное произведение нормалей, рассчитанное
точными рациональными операциями над двоичными координатами сохранённой сетки.
Выбираются хорошо разделённые плоскости; отсутствие такого свидетельства
означает **неизвестную подвижность**, а не разрешение блокировать домены.
В двухдоменной ветви общее движение больше не назначается без этого
свидетельства, кроме уже поддержанных полусферических координат.
Сертификат сохраняется в контактном состоянии, не создаёт новой силы.

## Граница дальнейшей работы

Положительного нерегулярного многодоменного сценария относительного движения
здесь **нет**. Поиск первого контакта не может дать положительный путь в
доказанно заблокированной конфигурации. Он всё ещё нужен для иных подвижных
конфигураций, но не устраняет этот контрпример общей цели.

Чтобы двигались произвольные родившиеся неровные плиты, потребуется изменить
геометрическую кинематику: например, разрешить реальную деформацию формы границ,
а не только хранить внутренние моменты при жёсткой форме. Перенос/удаление
материала и субдукция — другие изменения модели, а не параметры contact solver.
Таких изменений сейчас не делалось. Нужен отдельный выбор следующего
приближения; ещё одна серия уменьшений шага этот блокер не снимет.

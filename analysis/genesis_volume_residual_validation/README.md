# Остаток интерполяции: адресный успех, общий критерий не пройден

База: `64a8913055d90c0afb1ab1ca7bfb5b589ed0ffe1`.
Выполнены разрешённый повтор одной ячейки и, после его положительного
результата, три прежних малых опыта. Стратегия **не принята**: полный
критерий не выполнен. Четыре больших контроля не запускались.

## Адресная проверка и сохранённые значения

Касание Γ, треугольник 0, s=[1/2,1], t=[1/2,1]. Отдельно затрачены
**33 уникальных радиальных вычисления / 66 скалярных вызовов сторон**;
34 обращения сеток, одно точное совпадение узла. Все 33 интервала значений,
точные рациональные координаты, веса и якобианы сохранены в
`target_nodes.json`. Это реальные вычисления, не синтетическая подстановка.

Остаток coarse-значений относительно интерполяции fine-сетки выбирает **t**:

| Величина | Значение |
|---|---:|
| Центрированный маргинальный показатель s | 8,68724e−8 |
| Показатель t | 8,35399e−7 |
| Отношение t/s | 9,61639 |
| Среднее остатка | 4,60502e−7 |
| Взаимодействие осей | 4,71790e−7 |

Выбор согласуется с ранее измеренными детьми этого же родителя: деление
s оставляло в **31,89585 раза** больше исходного расхождения 3/5, чем t.
В новом малом опыте этот родитель действительно делится по t; отношение
дочерней к родительской оценке **0,0336422**. Так исправлена конкретная
ошибка прежней четвёртой разности, реагировавшей на форму fine-функции.
Отношение 9,62 не является прогнозом сокращения 31,90: эти величины
измеряют разные свойства. Ненулевое взаимодействие также сохраняется.

Независимый `target_audit.py` восстановил геометрию всех узлов и веса из
сохранённых лучей, проверил 33/34 и повторил интерполяцию отдельно от
рабочего модуля. Разрыв показателей **7,48527e−7**, граница его изменения
от сохранённой неопределённости **8,22683e−22**: выбор t устойчив.
Аудит не делает новых радиальных вызовов. Валидность исходных интервалов
опирается на ранее проверенный радиальный вычислитель; аудит не выдаётся
за вторую независимую оценку каждого физического волокна.

## Малый набор с прежними критериями

Рабочий индикатор читает готовые 3×3 и 5×5; **дополнительных радиальных
вызовов для него нет**. Приоритет ячейки, исходная оценка
`8·Σ|Q55−Q33|`, полная неопределённость [0,U], 2e−6, порядки 3/5,
лимиты 3400 / 2000 / глубина 24 сохранены. Аналитический объём используется
только после адаптации для проверки. Тензорный производственный интегратор
и физическая модель не изменены.

| Пример | Рабочие вызовы | Ячейки | Истинная ошибка − / + | Оценка / допуск − / + |
|---|---:|---:|---|---|
| Полушар | 3366 | 27 | 2,964e−6 / 2,948e−6 | 517,7 / 547,1 |
| Малый полушар | 3366 | 27 | 3,255e−6 / 3,237e−6 | 524,6 / 528,5 |
| Касание | 3399 | 53 | 2,779e−9 / 0 | 49,80 / 0 |

Максимальные отношения уменьшились с **671 / 665 / 127** до
**547 / 529 / 49,8**. Полушары по истинной ошибке всё ещё нарушают 2e−6;
касание проходит истинный объём, но не исходный embedded-критерий.
Ошибки coarse-правила остаются 9,69e−6…3,31e−5. Увеличивать допуск или
считать истинный объём заменой оценки нельзя.

Стоимость учтена раздельно: **33 диагностических + 10131 рабочих = 10164
радиальных вычисления**, или 20328 скалярных вызовов сторон. 33 не вычитаются
из отчёта и не прячутся в нулевой стоимости индикатора. Ни один рабочий
опыт не превысил собственный лимит 3400. В каждом каталоге опыта сохранён
`samples.json` со всеми полученными узловыми интервалами; дальнейшему
разбору этих узлов повторные вычисления не нужны.

## Почему локального исправления оказалось недостаточно

Маргинальный остаток выявляет недоразрешённую форму, но **не предсказывает
надёжно сокращение ошибки при делении**. Сопоставление одинаковых родителей
старого и нового варианта выявило 4 / 4 / 11 смен оси; в каждом примере
две из этих смен ухудшили наблюдаемую ошибку детей. Конкретно:

- Полушар, треугольник 2, s=[0,1], t=[1/2,1]: новое s вместо t хуже
  в **2,945 раза**.
- Малый полушар, тот же родитель: хуже в **4,234 раза**.
- Касание, треугольник 0, s=[0,1], t=[0,1/2]: новое s вместо t хуже
  в **2,368 раза**.

Это физические контрпримеры обобщению положительного адресного теста.
Все отношения и координаты сохранены в `summary.json`. Оставшаяся ошибка
также распределена: для 80% нужны 11 / 13 / 15 конечных ячеек.
Корневые интервалы занимают менее 0,025% допуска и не объясняют провал.

**Перебор индикаторов остановлен.** Нынешние данные показывают недостаток
предсказания результата деления; они не доказывают невозможность решения
при фиксированных порядках и лимите. Увеличение лимита сейчас нельзя
обосновать как необходимое или достаточное. Для следующего решения нужна
отдельная постановка: анализ регулярности/взаимодействия осей и связи
остатка с ошибкой детей на уже сохранённых значениях, с проверкой приведённых
контрпримеров. Новый адаптивный вариант в этом этапе не запускается.

## Аудит и воспроизведение

**121 тест PASS**, включая воспроизведение физической ячейки из сохранённых
значений без радиального вычислителя. Независимый аудит подтвердил
**581 луч, 931 корень, 3486 выборочных нулевых волокон и 107 конечных
ячеек**, точное покрытие без перекрытий, полную неопределённость и счёт
3366 / 3366 / 3399. Сам аудит покрытия и стоимости не использует
экспериментальный планировщик. Как прежде, это проверка скалярных
аналитических примеров, не общий сертификат углового тензорного остатка.

`summary.json` закрепляет SHA256 отчётов, лучей, узловых значений и
исходников; `independent_audit.json` и `target_audit.json` содержат проверки.
Для повторения нужны новые выходные пути; команды выполняют реальные
радиальные вычисления и должны учитываться как новые затраты:

```sh
python -m analysis.genesis_volume_residual_diagnosis.target_check --output /workspace/residual-target-NEW.json
python -m analysis.genesis_volume_residual_validation.experiment --case half_ball --output /workspace/residual-half-NEW
python -m analysis.genesis_volume_residual_validation.experiment --case small_half_ball --output /workspace/residual-small-NEW
python -m analysis.genesis_volume_residual_validation.experiment --case tangent_Gamma --output /workspace/residual-tangent-NEW
```

История Genesis и исходные данные сохранены. Восстановления, удаления,
публикации, новой эволюции и больших контролей не было.

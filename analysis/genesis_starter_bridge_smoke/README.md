# Starter: единая оболочка допустима; один шаг старой ветви проверен

**Это проверка старой приближённой ветви, не продолжение текущей объёмной
планетной истории.** Defaults, источники, архивы и принятое Genesis-состояние
0,8684 Myr / 800 когорт / четыре интервала не изменены. Restore CLOSED.

## Разрыв в предыдущей формулировке

`StarterModel.initial_state()` создаёт одно связное тело, без начальных плит,
повреждений и заданных разрезов. `advance()` принимает такой native StarterState.
Требования `first_partition` и минимум двух доменов принадлежат
`build_starter_continuation()` — переходу из Starter в mature.

Добавлен отдельный `assess_starter_entry(model, state)` в мост данных:
он вызывает штатную валидацию native-состояния, допускает одну оболочку и
учитывает штатную остановку. Объёмный пакет отвергается из-за отсутствующего
физического замыкания памяти, а не числа владельцев. Прежние `checks` в
transfer bundle относятся к прямой передаче в mature; их нельзя применять
как запрет единой оболочки для Starter. Старый пакет не переписан.

## Источник и происхождение разделения

Пригодные файлы найдены в
`analysis/genesis_origin_starter_validation/evidence/partition/`.
Пять входных файлов сверены с замороженным `package_manifest.json`.
Сохранённое частично остывшее состояние 0,65 Myr имеет одного владельца,
проходит native Starter validation и новый preflight. Сохранённый molten
checkpoint имеет одно тело, пустую историю разломов и нулевое повреждение.

Сохранённое разделение на две области — 0,89375 Myr, Starter 0.2,
subdivisions=2, нагрузка **50 kPa**, seed неоднородности **20260927**.
Это исторический контроль с повышенной нагрузкой, не канонические 20 kPa.
Скрипт `run_control.py` начинал с расплава и вызывал штатный `advance`;
разделение выбиралось по накопленной слабости, а не заданной карте плит.
Событие split и превышение штатного порога повреждения на полосе проверены.
При этом пространственные неоднородности и эффективная нагрузочная модель
заданы заранее: это не доказательство самопроизвольного физического 3D-разрушения.
Разделение в этом задании заново не рассчитывалось и seed не менялся.

Архив `handoff/cloud_sources.zip` содержит более старый Starter 0.1 без истории
рождения материала. Его не мигрировали с выдуманной историей и не использовали.

## Выполненный шаг и restart

Один новый шаг: **100 лет**, 0,89375 → 0,89385 Myr, в новом каталоге
`/workspace/starter-bridge-smoke-01/step`. Процесс имел жёсткий предел 240 секунд
и завершился с кодом 0; затем выполнены только чтение/сохранение/валидация,
без второго временного шага. Артефакты около **6,06 MB**.

```bash
timeout 240s env MPLCONFIGDIR=/tmp/habitable-moon-mpl \
 OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1 \
 /workspace/habitable-moon-venv/bin/python run_genesis_starter_continuation.py \
 --starter-checkpoint analysis/genesis_origin_starter_validation/evidence/partition/starter_checkpoint.npz \
 --output /workspace/starter-bridge-smoke-01/step \
 --duration-myr .0001 --step-myr .0001 \
 --frame-interval 1000000 --surface-only-frames
```

[Независимый отчёт](result.json): все семь проверок runner PASS — материальный
баланс, часы, повреждение, тепловая энергия, конденсация воды, оставшийся
материал и слэбовый запас. Материальный баланс использует штатную **единую
референтную плотность**, не видовой геохимический баланс.

Средняя скорость 0,01987789 km/Myr; изменились накопленные транспортные
кватернионы, возраст, повреждение и другие активные поля. Переносов ячеек 0,
новых разломов 0, источников/стоков коры 0. Это свидетельство работы шага
динамики и накопления малого движения, не доказательство уже развившейся
субдукции или образования континентов.

`verify_saved.py` проверил хеши выходного checkpoint, загрузил состояние,
сохранил его повторно и снова загрузил. Все **63 mature + 10 Starter + 8 fracture**
NPZ-полей совпали точно, mature metadata также совпала. Собран штатный
`YoungWorldCoupling` из повторно загруженных данных: часы и повреждение
согласованы, исходные когорты рождения и префикс интервалов сохранены.
Тепловое состояние/энтальпии входят в сравнение NPZ и metadata. Второй шаг
для проверки restart не выполнялся; равенство двух дальнейших траекторий
этой работой не заявляется.

Адресный набор: **20 тестов PASS за 0,62 с** — Starter entry, контракт
данных и маршрутизация существующего continuation CLI. Нового тестового
расчёта разделения этот набор не запускает.

## Один следующий блокер

Для **текущей объёмной Genesis → Starter** отсутствует физически обоснованное
замыкание объёмной Maxwell-памяти и глубинного теплового состояния в активные
эффективные поля Starter. Перенос имён полей/формата — технический адаптер;
замена этой памяти одним cooling_stress или средним возрастом — физическое
приближение. Сохранённые остатки нельзя просто оставить пассивным архивом
и объявить продолжением той же физики. Следующий конечный результат должен
определить активное использование или доказанный предел влияния этих остатков.
Число владельцев этому не препятствует. Новые thresholds здесь не введены.

# Локальная чувствительность физических выводов к численной точности

База: `632e0fbe4e1aa84941eac2df0b519235e88f52e1`. Рабочий допуск 2e−6
не изменён. Новых угловых интеграторов, четырёх пространственных контролей
и эволюции Genesis нет. Это ограниченный опыт доступного локального
когезионного закона, **не калибровка материала или всей планеты**.

## Заранее фиксированные условия

Взяты параметры существующего `tests/test_genesis_volume_creation_law.py`:
Gc=1 МДж/м², T=4 МПа, k=10⁹ Па/м, жёсткость сжатия 2·10⁹ Па/м.
Площадь каждой независимой пробной площадки — 1 м², пик раскрытия
δ₀=T/k=0,004 м, полное разделение δf=2Gc/T=0,5 м.
Эти числа не выведены из принятой истории Genesis и не объявлены
физически откалиброванными. Две площадки ниже — не два берега одной Γ.

Выбраны три фиксированных состояния:

1. Обычное монотонное раскрытие: 0 → 0,0123 м, с пересечением пика тяги.
2. Компенсация: упругое сдвиговое нагружение первой площадки 0 → 0,001 м;
   разгрузка второй −√2·0,001 → −0,001·(1−10⁻⁸) м. Силы почти
   противоположны; положительная и отрицательная работы почти компенсируются.
3. Вблизи порога: 0 → δ₀·(1+10⁻⁶), запас по заданному раскрытию ≈4 нм.

Смещения **заданы, не предсказаны механическим решателем**. Измеряются
тяга в Па (напряжение на интерфейсе), сила в Н, работа, запасённая энергия
и диссипация в Дж. Объёмный тензор напряжений этим опытом не проверяется.

Интеграл работы вычислен по тягам методом трапеций на 8, 32, 128 равных
подынтервалах каждого пути. Это три уровня точности только изолированного
теста. Ответы сил в конечной точке от этой сетки не зависят; их постоянство
нельзя выдавать за исследование сходимости связанной механики.

Эталон — отдельная рациональная первообразная кусочно-линейной тяги;
для упругой разгрузки используется k(δnew²−δold²)/2. Эталон не читает
энергию или повреждение вычислителя. Баланс проверяется как независимо
интегрированная работа минус ΔU+D; равенство `reported_work=ΔU+D` само
по себе не считается независимой проверкой. Второй аудитор использует
площадь трапеций диаграммы тяги и точную формулу ошибки на её изломе.

## Измеренное сравнение

| Состояние | Эталон суммарной работы, Дж | Ошибка при 8 / 32 / 128 интервалах, Дж |
|---|---:|---|
| Обычное | 40922,2177419 | 285,566 / 17,9660 / 1,08965 |
| Компенсация | −1,000000014·10⁻⁵ | 5,41·10⁻¹⁴ / 5,41·10⁻¹⁴ / 1,16·10⁻¹³ |
| Около пика | 8000,0159999999 | 0,00100806 / 0,000252008 / 0,0000629960 |

Для обычной работы относительные ошибки 0,006978 / 0,0004390 /
0,00002663: даже 128 интервалов не достигают 2e−6. Положительный знак
работы при этом устойчив на всех трёх уровнях; это гораздо более слабая
задача, чем точное значение работы. Для близкого к пику состояния все
три уровня проходят 2e−6 по работе.

В компенсированном случае результирующая сила ≈0,01 Н при отдельных
силах около ±10⁶ Н. Ошибка результирующей силы ≈6,71·10⁻¹¹ Н;
ошибка работы относительно её малого остатка ≤1,17·10⁻⁸. Поэтому
**чисто относительный 2e−6 здесь проходит**: сам факт компенсации не
доказывает недостаточность вычислителя. Нельзя заменять сумму работ
разных площадок произведением результирующей силы на одно смещение.

Ошибки конечной тяги/силы против рационального эталона составляют
примерно 9,45·10⁻¹⁰ Н для обычной площадки и 2,77·10⁻¹¹ Н около пика.
Независимый эталон работы отличается от ΔU+D каждого локального ответа
не более чем на 7,01·10⁻¹² Дж. Это поддерживает локальное ядро;
неудача трапеций связана с интегрированием излома диаграммы тяги.
Пространственная квадратура объёмных операторов в этот вывод не входит.

## Чисто относительный и смешанный критерии — только диагностика

До получения результатов зафиксированы физические масштабы:
S_F=Σ площадь·T, S_W=Σ площадь·Gc, S_δ=δ₀.
Они имеют единицы Н, Дж и м и не зависят от маленького остатка.
Сравниваются `E≤ε|y|` и `E≤εS_y+ε|y|`, при ε=2e−6.
Это предлагаемая форма бюджета, **не доказанное физическое разрешение**.

При обычной нагрузке чистый допуск работы ≈0,08184 Дж; смешанный
≈2,08184 Дж. Ошибка 128-интервального результата 1,08965 Дж проходит
только смешанный критерий. Это не основание принять его: приемлемость
ошибки в 1–2 Дж для механического решения ещё не определена.

Особенно показателен компенсированный случай: смешанный абсолютный член
по работе равен 4 Дж, хотя остаток работы всего −10⁻⁵ Дж. Такой критерий
разрешал бы ошибку, меняющую знак, даже если этот конкретный вычисленный
ответ весьма точен. Поэтому смешанного теста без контроля знака/порога
недостаточно. Для решения о знаке нужен абсолютный интервал ошибки,
не пересекающий ноль; для данного остатка это требует ошибки <10⁻⁵ Дж.

## Порог и гипотетическая неопределённость входа

Отдельно, заранее, выбраны уровни ε=10⁻⁴, 2·10⁻⁶, 10⁻⁸. Это
**сценарии предполагаемой ошибки**, не измеренная ошибка интегратора.
Для около-порогового состояния проверены реальные ответы ядра при
раскрытии δcenter±εδ₀:

| ε | Предполагаемая ошибка раскрытия | Однозначно выше пика? |
|---|---:|---|
| 10⁻⁴ | 400 нм | Нет |
| 2·10⁻⁶ | 8 нм | Нет |
| 10⁻⁸ | 0,04 нм | Да |

Запас до пика всего 4 нм. Для устойчивого вывода в **этом заданном**
состоянии требуется ошибка раскрытия меньше запаса, то есть <4 нм,
или <10⁻⁶ от δ₀, без учёта неопределённости самого порога.
Это не требование считать все интегралы до 10⁻⁸: связь ошибки интегралов
с ошибкой предсказанного раскрытия здесь не построена. У заданного входа
нет измеренной неопределённости в 8 нм — она введена явно как сценарий.

## Что можно предварительно обосновать

- Для локальной работы имеющееся аналитическое ядро согласуется с
  независимым эталоном гораздо точнее 2e−6. Грубое интегрирование его
  тяг может быть хуже; экономия на точности требует оценки нужного выхода.
- Для знака работы нужен бюджет относительно запаса до нуля; для
  активации — относительно расстояния до порога с учётом ошибки порога.
  Один относительный процент не заменяет эти два условия.
- Конкретные измеренные пороги разрешения здесь: около 0,08184 Дж для
  обычной работы при сохранении 2e−6; <10⁻⁵ Дж для знака компенсированной
  работы; <4 нм для около-порогового заданного раскрытия. Это разные задачи.

Не установлены требуемая точность общего тензорного интеграла, сил и
перемещений связанного решателя, неопределённость материальных параметров
Genesis и ошибка эволюции. Сквозное исследование ограничивают отсутствие
допущенных пространственных интегралов и откалиброванного закона активации.
Числового основания заменить рабочий 2e−6 новым общим допуском пока нет.

Следующий отдельный шаг: выбрать физически нужное разрешение силы/работы
и допустимую неопределённость событий, затем на фиксированном локальном
механическом подпространстве проверить перенос ограниченных возмущений
оператора в силы/работу/предсказанное смещение и запас до порога. Нужны
достоверные границы оператора и устойчивость решателя; их нельзя заменить
произвольным возмущением и назвать доказательством. Бюджет исследования
и изменение рабочего критерия остаются отдельными решениями.

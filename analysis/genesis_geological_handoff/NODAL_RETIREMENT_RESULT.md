# Приближённый handoff узловой оболочки: исправление барьера

13.10.2026; база `045a157f7d7d6e5263166631d9e25a41d41e9680`,
ветка `feat/genesis-geological-handoff`. Активная задача — handoff, не восстановление
публикации. Старый restoration plan не является текущим поручением.

## Исправленный вывод

Предыдущий `REAL_HANDOFF_NOT_READY` получен при вызове устаревшего для этой
задачи `GeologicalContinuation.from_synthetic` из `3a65aba`. Это ограничение
синтетического интерфейса, а не запрет уже разрешённого приближённого перехода.
`ThermalGeologicalContinuation.from_source` из `8d7912b` уже переносит массу/H,
использует существующие thermal ports и native material transport, архивирует
механическую память без тепла. Неизвестный элементный состав не блокирует
режим undifferentiated silicate; континентальный состав не выдумывается.
Полный контактный solver и активное продолжение Maxwell-памяти здесь не нужны.

Недоставало явного отображения shared nodal velocities в вращения областей и
учёта фактических узловых K/L/P. Это добавлено только через
`experimental_nodal_retirement=True` и явно переданную, топологически проверенную
границу. Исходный config/state сохраняется целиком, включая исходный owner.
Массово-взвешенная аппроксимация скоростей центров верхних граней даёт Euler omega;
остаток fit, исходные и новые импульсы, signed changes записаны. Деформации и
наклоны узлов архивируются, а не продолжаются геологической моделью.
Каноническое отображение по face ID остаётся прежним приближением геометрии.

Сохранены запреты: незамкнутая/неразделяющая граница, диффузное разрушение,
малые фрагменты, независимая edge geometry, конечные вращения без remap,
newborn-профили без parcel mapping, несогласованные массы/EOS/часы.
Обычный вызов без opt-in по-прежнему отклоняет nodal source.

## Две разные проверки

**Искусственная граница на настоящем раннем source:** полусферы заданы только
для проверки адаптера. Масса и H всех 2722 узлов совпадают буквально; source
не изменён. Два native шага по25лет и save/load дают точное совпадение restart.
На этих коротких шагах перемещения между winning cells ещё нет; действующий
перенос созданной/переработанной массы и H проверяется существующим

Экспериментальный предвестник вычисляет полное тензорное напряжение из памяти,
сдвиговую тягу на межгранной поверхности и накопление
`Dedge += dt/100years * max(shear/1MPa−1,0)^2`, ограниченное единицей.
Он заменяет старый onset selector лишь при явной опции. Это **incubation-only**
до принятого перехода: жёсткость общих узлов не ослабляется, дополнительное тепло
не создаётся. Это другая предразрывная аппроксимация, чем скалярная пружинная сеть;
её результаты нельзя выдавать за интеграцию той сети в векторную механику.
Старый damage и его физический heat ledger продолжают действовать.

На первом шаге Dedge=1 у48/120 связей (40%), shear max6.284MPa;
на последнем84/120 (70%), shear max4.567MPa. Все предложения отклонены
`DIFFUSE_NETWORK_FAILURE` при прежнем лимите35%. Это насыщенный индикатор,
не фактическое отключение связей в узловой механике. Owner не менялся.
Сертифицированное событие, если возникнет, блокирует следующий nodal step до
явной передачи; при неподдерживаемом newborn/remap переход также остановится.
Никакой траектории разделившихся реальных плит здесь не получено.

Whole-energy residual/allowance ≤.037284 на всех20 шагах. Последний шаг
точно воспроизведён из restart; первый opt-in шаг имеет те же energy/memory/
nodal_velocity/old damage, что default. Исходник и прежний endpoint .8991Myr
(SHA256 `7dd22796ca517d8866505b7bf374847f03300117fc5eda0c012f27712035648b`)
остались побайтово прежними. Новый пилот их не заменяет.
Сходимость времени насыщения индикатора по dt/сетке не проверена; параметр1MPa
не калиброван по результату, физический прогноз разломов не заявлен.

## Что означают прежние 500 лет скалярного опыта

На320/1280 гранях maxD=.9748467/.9807528. До строгого D=1 остаётся
.0251533/.0192472; остаточная относительная жёсткость наиболее повреждённой
связи `(1−D)^2` ≈.0006327/.0003705. Это очень слабые, но ещё целые связи.
Начальный max traction1.902/1.925MPa, конечный1.108/1.117MPa при Y=1MPa.
Полностью разорванных связей0, поэтому замкнутого отделения нет.
Отрицательный результат500лет не доказывает невозможность позднего разрыва;
порог не снижен ради получения плит.

## Итог и следующий технический шаг

Программный барьер приближённой передачи для проверенного раннего source снят.
Текущий реальный барьер — отсутствие допустимой локализованной замкнутой границы:
опробованный индикатор даёт диффузное насыщение. Нужно отдельно исследовать
пространственную локализацию/чувствительность этого правила, не ослабляя
certificate и не выбирая желаемый split. Для позднего source с newborn остаётся
конкретная дополнительная работа: parcel mapping переменных профилей.
Полная контактная механика не является prerequisite данного режима.

Машинные результаты: `nodal_retirement_result.json`; воспроизводимый runner:
`nodal_retirement_check.py` (намеренно требует нового output directory).
Планетные defaults, каноническая история, прежние checkpoint сохранены.
No push/paid/restore. Новый пилот завершён; повторное восстановление не требуется.

Проверки кода: 25 PASS в общем наборе geological handoff/thermal/nodal/new
adapter; затем6 PASS для адаптера с добавленным независимым rigid-rotation
контролем (26 различных тестов суммарно). `git diff --check` PASS.

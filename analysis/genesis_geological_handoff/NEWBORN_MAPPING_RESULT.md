# Newborn-профили: экспериментальный handoff реализован

Ветка feat/genesis-geological-handoff, после46b359e. Вводится явная опция
`experimental_parcel_mapping=True`; без неё прежний newborn guard сохранён.
Источник с80новыми профилями .8991Myr:240активных тепловых узлов вместо160,
исходные mass/H массивы совпадают буквально. Дополнительная масса взята из
уже существующего thermal inventory, не добавлена повторно. Состав остаётся
представленным undifferentiated silicate с неизвестными элементными долями;
никаких континентальных/химических фракций не выдумывается.

Каждая грань получает список исходных и born узлов, упорядоченных по профилю.
Проверяются уникальность cell/node, принадлежность face, mass/volume и solidus;
число слоёв не обязано совпадать. При native material transport источник
задаёт полный профиль, который консервативно делится по накопленной массовой
координате между фиксированными узлами принимающей грани. Сохраняются ID,
origin_face, birth_cell_id, composition, масса/H фрагментов; локальные проверки
каждого ID не прячутся за большим глубоким резервуаром. Без перемещения
профиль сохраняется буквально. После thermal solve фрагменты внутри одного
узла получают его общую удельную H: это явное смешение, не точное сохранение
вертикальной температурной формы и не движущаяся тепловая геометрия.

Создание native материала дебетует старый deep donor, recycling возвращает
свои mass/H; поглощённые идентификаторы записаны в архивный ledger глубокого
смешанного резервуара, не вторую активную массу. Новый native материал имеет
новый ID и тот же недифференцированный состав. Полная elemental chemistry
и восстановление идентичности после плавления/смешения не моделируются.
Исходный fixed Eulerian thermal graph и его EOS сохранены. Будущее promotion
ещё не твёрдых interior cells после смены модели не добавлено: это поддержка
уже принятых newborn-профилей плюс существующего native рождения материала.

Механическая память полностью архивируется. Узловой rotational fit теперь
взвешивается массой исходного и newborn материала. K/L/P и elastic включают
newborn; signed model change, passive/edge reserves не превращаются в тепло.
Полный контакт не требуется этим выбранным режимом.

Проверки: unequal2/3слоя, добавленный четвёртый слой manufactured admission,
сохранение каждого ID при remap, новые parcels/recycling, отрицательные
identity/duplication проверки, атомарный отказ, native transport/creation,
реальный поздний inventory с manufactured closed boundary и exact restart.
23 регрессионных/первых проверок PASS; расширенный newborn набор7 PASS.
Нативный транспорт tested на отдельном synthetic fixture; его большие единицы
времени не являются продолжением реальной планеты.

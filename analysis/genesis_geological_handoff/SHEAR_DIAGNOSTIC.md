## Задача и заранее выбранные параметры

Строго отдельный периодический одномерный стенд простого сдвига: скорость
направлена по x, меняется по y, `gamma=du_x/dy`. Квазистатическое равновесие
`d tau_xy/dy=0` делает tau одинаковым во всех ячейках. Задана средняя скорость
сдвига, локальная скорость не навязана. Инерция, basal drag, damage, приливы,
рост вещества и температурная обратная связь отсутствуют. Температура фиксирована,
диссипация передаётся изотермическому тепловому резервуару и учитывается отдельно.
Это намеренно более простая проверка механизма, не тест переноса двухмоментной
планетной дискретизации и не эволюция её checkpoint.

| Параметр | Значение и смысл в эксперименте |
|---|---|
| Период L, длина Helmholtz ell | 128 km, 8 km; выбраны для разрешения ell на 8/16 ячейках, не по данным коры |
| G, tau_ref | 20 GPa, 1 MPa; независимые масштабы перевода в SI, не tensile 12 MPa |
| t_ref, gamma_ref=tau_ref/G | 1 Julian year = 31557600 s; 5e-5 |
| Средняя gamma_dot | gamma_ref/t_ref = 1.5844e-12 s^-1 |
| Время Maxwell eta_M/G | 100 years; eta_M=6.31152e19 Pa s; медленная релаксация относительно теста |
| eta_p | .1 G t_ref = 6.31152e16 Pa s; вязкопластическое время .1 year разрешено шагом |
| Начальная shear yield Y0 | tau_ref×(1-.001 f(y)); слабая аналитическая неоднородность ≤0.1% |
| Остаточная Y_res | .4 Y0 в B; A сохраняет Y0 |
| Критическая kappa_c | 5 gamma_ref = 2.5e-4; накопленная инженерная пластическая сдвиговая деформация |
| Длительность, шаг | 12 years; .025 year и контроль .0125 year |

Один набор отношений выбран до запуска: текучесть начинается примерно через
один t_ref, ослабление успевает пройти до остаточной прочности за 12 t_ref;
минимальное время линейной обратной связи eta_p*kappa_c/(Y0-Y_res) около
.833 year, существенно больше шага. Это **демонстрационный диапазон**, не
измеренные параметры и не поиск параметров, дающих полосу. Варьировались только
разрешение/шаг. Начальные kappa, tau, gamma равны нулю. Идентичное для A/B
аналитическое возмущение:

`f(y)=[cos(2pi y/L)+.5 sin(4pi y/L)+.25 cos(6pi y/L)]/1.75`.

Оно содержит широкие гармоники L, L/2, L/3, не готовый узкий пояс. При смене
сетки вычисляется то же поле в центрах ячеек. Никакие seed плит не используются.

## Закон, регуляризация и конвенции

```
gamma_dot = tau_dot/G + tau/eta_M + gamma_dot_p
gamma_dot_p = max(tau-Y,0)/eta_p             # только положительный сдвиг этого теста
kappa_dot = gamma_dot_p
Y_B = Y0 * [.4+.6 max(1-bar_kappa/kappa_c,0)]
Y_A = Y0
(1-ell² d²/dy²) bar_kappa = kappa           # периодическая граница
```

Полный тензор имеет только sigma_xy=sigma_yx=tau, поэтому p=0, J2=tau²,
q=sqrt(3)|tau|. Здесь kappa есть инженерный пластический сдвиг, а не эквивалентная
деформация: `kappa_eq=kappa/sqrt(3)`. Соответственно Y_q=sqrt(3)Y,
eta_p,q=3 eta_p при записи `lambda_dot=(q-Y_q)/eta_p,q`. Гидростатическое и
поровое давление в задаче отсутствуют; трение/дилатансия не исследуются.
Это когезионный сдвиговый предел предложенной ветви, не проверка давления-зависимого
закона. Для обратного сдвига реализация не заявлена.

Maxwell здесь определён через **G/eta_M**, естественно для скалярного сдвига.
Это не молчаливое исправление планетного **E/eta**: импортов/изменений того
оператора нет, численное сравнение с его вязкостью не проводится.

Helmholtz решается FFT с собственными значениями именно конечно-объёмного
периодического Laplacian. Шаги h=1 km и .5 km; ell/h=8 и 16. Ядро положительно,
нормировано и поддерживается всем периодическим доменом, а не радиусом ell.
Масса дискретного ядра на расстоянии ≤ell: .65484/.64355 (континуальный ориентир
около .632 для бесконечной линии); дискретный подсчёт включает граничную ячейку.
Поэтому «8 km» — длина затухания, не измеренная ширина полосы. Сравнение двух
сеток показывает слабую зависимость метрик в этой гладкой задаче; оно не
доказывает объективность произвольных узких/планетных полос или правильность ell.

## Решение и энергия

Неявный BE шаг совместно замыкает tau, kappa и bar_kappa: внешний fixed-point
по ослаблению, локальный положительный поток и скалярный solve среднего сдвига.
Максимум 9 итераций в B, 2 в A; несходимость вызывает ошибку, не скрытую обрезку.
Равномерный tau удовлетворяет пространственному равновесию точно.

Работа и энергия на единицу объёма:

```
Wext = tau1 * Delta mean(gamma)
Delta U = (tau1²-tau0²)/(2G)
QM = dt*tau1²/eta_M
Wp = mean(tau1*Delta gamma_p)
N_BE = (tau1-tau0)²/(2G)
Delta U + QM + Wp + N_BE - Wext = 0
Wp = mean(Y1*Delta gamma_p + eta_p*Delta gamma_p²/dt)
```

Последняя строка — разложение уже учтённого Wp, не второй тепловой источник.
QM и Wp идут в тепло, N_BE остаётся численным дефектом. Внутренней запасённой
энергии kappa не предполагается; ослабление меняет yield, не G. Damage, drag,
thermal_work записаны отдельными нулевыми строками. Следовательно дополнительное
`-Delta U_damage` здесь отсутствует: двойной диссипации damage/plastic нет.
Единица энергий JSON — tau_ref*gamma_ref=50 J/m³.

CV=std(gamma_dot_p)/mean(gamma_dot_p). Эффективная ширина
`L*mean(flow)²/mean(flow²)` — participation width, не геометрическая ширина
разлома. Метрики потока вычисляются при mean(flow)>.1 заданной скорости,
чтобы первое включение отдельных ячеек при почти нулевом потоке не изображать
как развитую полосу. Максимум B около 5.275 year, ширина около 118.89 km.
Усиление std B/A=8.893; даже нормированный на собственное среднее разброс B
выше A, то есть это не просто увеличение общей деформации.

Сгущение: std отличается на .01162%, эффективная ширина на .001384%.
Половинный шаг: std отличается на 2.5826%, ширина на .3084%. Качественный
результат устойчив, полную временную сходимость по двум шагам не заявляем.
Ни положительный результат этого теста, ни прежний gain=.99334 одного
направления tensile-D не являются полным анализом спектра устойчивости.

Максимальный пошаговый остаток энергии <3.9e-16 в единицах JSON;
полный остаток <7.3e-14, ошибка среднего сдвига <2.2e-13 в единицах gamma_ref.
На B128: Wext=7.455033, QM=.051284, Wp=7.265173, N_BE=.013826,
Ufinal=.124750. Все физические диссипации неотрицательны.
Restart B128 после половины интервала через реальный JSON-файл дал точное
совпадение конечного состояния, истории и ledger. Четыре независимых контроля
PASS: постоянная/гармоника фильтра и положительность ядра; аналитический
Maxwell-предел без пластичности; аналитический однородный return map и энергия;
сохранение однородности без возмущения при включённом ослаблении.

Первый запуск набора занял 1.89 s; повтор после добавления файлового restart

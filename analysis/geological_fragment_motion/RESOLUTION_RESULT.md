ветка `feat/unified-geological-genesis`. Физические модули не изменены.

## Общие условия

Сравниваются 320 и 1280 сферических треугольников (subdivision 2 и 3).
Площадь ячейки уменьшается примерно вчетверо, линейный масштаб — вдвое.
Обе ветви проходят один шаг 0,25 млн лет: **200,8684 → 201,1184 млн лет**.
Запуски последовательные, OPENBLAS/OMP по одному потоку; на каждую ветвь
установлен жёсткий лимит 240 с вместе с повтором.

Это две инициализации дробного режима из общего подтверждённого источника
`/workspace/geological-contact-area/dt1/accepted`, который использовался и в
предыдущем `geological_fractional/VALIDATED_RESULT.md`. Это НЕ перенос
последнего fractional checkpoint времени 201,8684: готового проверенного
переноса его раздробленных полигонов между сетками нет. Последнее сохранение
не изменено; каноническая история не сбрасывается.

Вложенное уточнение сохраняет постоянные внутри родителя высоты, возраст,
состав, ослабление, мантийное поле и принадлежность плите. Объёмы, массы,
энтальпии и каждый материальный ID делятся по сферическим площадям дочерних
ячеек. Оба глубоких/водных резервуара неизменны. Сохраняются восемь угловых
скоростей, память 32 slab-зон и история; нового силового закона нет.
Счётчики минимальной площади в ячейках умножены на 4, минимальной длины
рифта в ячейках — на 2; заданные физические площади и длины неизменны.
Это приближённое соответствие дискретных критериев, не доказательство
сходимости топологических событий.

Перенос: глобальные остатки массы/H равны 0; максимальная относительная
невязка по 1013 материальным ID — **2,7801e−16**. Проверены суммы объёмов.
До шага совпадают береговые доли, высоты, владельцы и скорости на общих точках.
Уточнение не добавляет неизвестного субъячеечного рельефа.

## Стоимость и следующий шаг

Уточнение замедлило шаг в **3,377 раза**. Линейная оценка при dt=0,25 для
100 млн лет: **1,43 ч / 4,83 ч**, для 500 млн лет: **7,16 ч / 24,17 ч**.
Это грубая экстраполяция по одному шагу, без повторов и частых сохранений:
рост числа полигонов и события топологии могут резко увеличить стоимость.
Большой прогон не запущен. Данные теста занимают около 58 MiB;
после теста свободно около 1,99 GB.

Балансы и близкое движение плит допускают следующий ограниченный тест,
но заметное различие берегов не позволяет объявить пространственную
сходимость или автоматически заменить 320 на 1280. Следующий разумный шаг —
2–4 шага на обеих сетках с сохранением после каждого, оценкой роста полигонов
и раздельной диагностикой рельефа/внутрячеечных береговых долей; затем
контроль dt=0,125. Полную эволюцию на мелкой сетке пока не запускать.

Выполнены 13 регрессионных тестов fractional/unified (5,13 с), проверки
материального переноса на настоящем источнике и два точных restart.
Синтетический сглаженный рисунок не использовался как расчётный результат.

## Повторение

Из корня репозитория с проектным Python и одним потоком:

```sh
python -m analysis.geological_fragment_motion.resolution NEW_ROOT/coarse
python -m analysis.geological_fragment_motion.resolution NEW_ROOT/fine --fine
python -m analysis.geological_fragment_motion.compare_resolution NEW_ROOT SUMMARY.json
python -m analysis.geological_fragment_motion.surface NEW_ROOT/fine/accepted MAP.png
```

Каталоги создаются исключительно новыми; существующие состояния не перезаписываются.
PNG этого теста: `/workspace/habitable-moon-resolution-1280.png`.

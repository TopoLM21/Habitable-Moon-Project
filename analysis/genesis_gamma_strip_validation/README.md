## Метод и предел зафиксированы до проверки

Набор: `1258,1255,1270,1267,1257,1256,1269,1268,1301,1300,1305,1304,1230,1225,1229,1226`.
Ни один блок не добавлялся по результату вычисления работы.

Γ — мультиаффинный полином в исходных N1,N2,lambda. Для каждой возможной
оси проверяется однозначный знак производной по всему прямоугольнику.
Из допустимых осей выбирается та, где диапазон положения корня уже;
используется только геометрия Γ, не знак работы. Во всех 16 случаях
выбрана ось N2. Две поперечные координаты делятся пополам: четыре части.

В каждой части Γ линейна вдоль выбранной оси. При постоянном знаке
знаменателя экстремумы отношения её мультиаффинных коэффициентов по
поперечным координатам достигаются на углах. Четыре точных рациональных
корня дают полосу, содержащую все пересечения Γ. Полоса ограничивается
исходным блоком. Получаются от одной до трёх неперекрывающихся полос.

На каждой полосе используется прежнее строгое полиномиальное включение:
сфера и Γ классифицируются по точным коэффициентам Бернштейна; при известном
знаке Γ внутри сферы работа интегрируется точно. Неопределённая полоса
сохраняет двустороннюю границу через интегралы положительного и отрицательного
коэффициентных огибающих. Даже за пределами центральной полосы знак проверяется
самим сертификатом; никакая область не объявляется положительной по предположению.

Предел объявлен: 16 исходных блоков, 64 поперечных части, не более 192 полос,
120 секунд вычислений; без нового регионального поиска. Неоконченный блок
сохраняет прежние границы. Пересечение старого и нового строгих включений
допустимо; произвольная замена отрицательной границы нулём не производится.

## Независимая проверка

Аудитор не импортирует выбор корневой полосы или экспериментальное преобразование
Бернштейна. Он:

- проверяет SHA256 старого региона, его исходника и независимого аудита;
- повторно проверяет исходное дерево покрытия и старую полную сумму;
- проверяет четыре поперечные части и непрерывное покрытие каждой полосами;
- независимо проверяет точные угловые корни Γ;
- обратным преобразованием восстанавливает все 510 полиномиальных тождеств
  для 170 полос и проверяет каждое signed-включение;
- через мономиальные первообразные проверяет интегралы и сохранение полного
  интеграла плотности каждого родителя;
- подтверждает границы, знак каждого выбранного блока и полную сумму.

Включения неизменённых 849 вкладов используются из прежнего аудита,
связанного SHA256; их полиномы заново не интегрировались. Это явное повторное
использование доказательства, а не новый полный аудит всей истории проекта.

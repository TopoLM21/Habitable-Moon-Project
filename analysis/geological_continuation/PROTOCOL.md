# Продолжение общего геологического пути

Задача после `138d398`: геометрия жёстких доменов и перенос, затем зрелые
continental cycle / subduction memory с mass/H, сравнение dt1/.5 и b0ba7e5.
Никаких целевых карт/чисел плит, изменений canonical YAML, push или удаления
старых результатов. Молодой старт остаётся тем же принятым состоянием0.8684Myr.

## Техническая геометрия

Trace разделяет: единое quaternion-вращение; дискретное назначение ячеек;
разрешение перекрытий; поздний topology repair. На70.8684Myr в исходной
ветви одна плита имеет2компонента уже после назначения, другая получает
одиночную ячейку после перекрытия. У ячейки нет своей угловой скорости.

Связная проекция — опция `connected_footprint`, defaultFalse. Она начинает
с прежней minimum-distance bijection, соединяет только разрозненные компоненты
кратчайшими сеточными путями и обменивает избыточные пограничные ячейки.
Число исходных материальных колонок сохраняется, их назначение взаимно
однозначно. Добавленная локальная коррекция ограничена1.5типичного расстояния
между ячейками; непредставимое назначение отвергается. Это растровое правило,
не независимое движение клеток и не разрешённая физическая деформация.
Контакты способны отделить материал после этого шага; такие исправления
владельцев считаются отдельно от физических split.

Отброшенный вариант глобального связного заполнения уменьшал разрывы, но
давал ошибку5578км. Он **не принят**; свидетельство сохранено в
`/workspace/geological-geometry-01/`. Локальная версия до подключения цикла:
`/workspace/geological-geometry-02/`, raw-extra116→0, overlap-extra21→1,
repair20→1, максимальная ошибка869→1259км. Уменьшение dt не заменяет эту правку.

Повреждённая область214ячеек и граница разделения — разные объекты.
[Диагностика](split_geometry.json): два связных домена174/146ячеек,
28рёбер длиной45314.5км, одна замкнутая граница с degree2 во всех вершинах.
Карта: [split_geometry.png](split_geometry.png). Разделение не задаёт
скоростного толчка; дочерние плиты наследуют вращение родителя.

## Общие зрелые процессы и новые допущения

Используются прежние `advance_continental_cycle`, `refresh_mechanical_lithosphere`,
`advance_subduction_memory`, residual slab pull, `advance_late_tectonics` и
PlateTopologyManager. Их значения dataclass-параметров записаны в checkpoint.
Континентальное вещество создаётся после native arc maturation, не по одной
толщине мафической коры. Действуют рост, эрозия и деламинация. Материальная
трасса учитывает всех прибывших континентальных доноров, а не только победителя
видимого владельца, и все локальные transfers/cycle stages.

Фрагменты сохраняют origin ID, process, birth time, mafic/felsic label, m/H.
Кора берётся из конечного хорошо перемешанного внутреннего резервуара с его
удельной энтальпией; возвращается с фактической H. Субдукционная length/depth
memory — силовая диагностика, **не вторая копия массы**, уже возвращённой
в interior. Старые записанные тепловые профили не объявляются новой химией.

Явные феноменологические допущения:

1. Оба типа вещества имеют общую опорную плотность3000кг/м³ и прежний silicate
   EOS. Это эквивалентный rock-volume/mass ledger, не элементный состав.
2. Расширение континентального покрова вытесняет соответствующую долю
   подстилающего учтённого базальта в interior вместе с H. Опция
   `continental_displacement=retire_displaced_basalt`, прежний defaultNone.
   Необходимость выявлена реальным отказом на178.8684Myr: при полном
   континентальном покрытии оставался basalt volume без площади. Это **новое
   сценарное правило**, не техническая победа над физической неопределённостью.
3. Сохранены прежние сценарные гладкая мантийная тяга, закон слабости и
   жидкий300K океан с экспортом тепла. Радиогенное/приливное тепло, климат,
   полный sediment/plume/rollback/breakoff цикл здесь не включены. Native
   degree-2 tidal fatigue использует исходные e4.380327385e−5,h2.6,5Mj,
   Kepler period47.1468257h. Достаточность одних приливов не утверждается.

Чисто технические исправления: ограничение roundoff-only overflow доли площади
до1 (≤16ULP, без удаления объёма); сохранение фрагментов меньше ULP накопленной
массовой координаты; объединение одинаковых fragment IDs **внутри одного
теплового узла**, без межузлового смешивания; линейная вместо квадратичной
проверка ID-балансов. Абсолютный допуск сравнения маленького потока с разностью
крупных накопленных счётчиков берётся из уже действующего native volume ledger.
Численные остатки сохраняются отдельно.

## Ограниченные прогоны

Сначала адресные регрессии и160Myr smoke; затем по500Myr приdt1/.5.
Wall budget300s на попытку, без многодневных циклов. Реальные отказы сохранены:
`geological-mature-failure-01`, `geological-continuation-01/02`.
После выявления роста дубликатов попытка03 остановлена; обе ветви продолжены
из собственных сохранений200.8684Myr в04, с сохранением всей предыдущей истории.
Нет перезапуска Genesis, сброса возраста или замены старых checkpoints.

Контроль — полный неизменённый runner из git archive
`b0ba7e51da0177447aec4fb632cec1c154e9504d`, canonical-параметры этого коммита,
только subdivision2 и dt1/.5 заданы во внешней копии config. Снимки считаются
одним `diagnostics.py`: area-weighted surface speed, connected owner count,
actual continental material fraction, land fraction, sea datum, water inventory,
floor geometry. Observer wrappers возвращают исходные результаты без изменения.
В старом baseline нет полного mafic+interior H/mass ledger: его нельзя
выдумывать из сохранения континентального объёма.

Контроль начинается со зрелого мира с континентами и другим запасом воды/e,
поэтому различия между сценариями не приписываются одной правке. Парные
различия dt внутри каждого сценария публикуются отдельно; физическая
сходимость по одному совпадению скорости не объявляется.

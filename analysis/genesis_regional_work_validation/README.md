# Полная региональная виртуальная работа: знак UNRESOLVED

Реальный сохранённый участок `case_000_fixed_100m_clipped_support`, cohort 1 /
face 0, радиус 100 м; фиксированная проба `saved_accepted_interval_mean`.
Это заданные пробные смещения с принятой памятью материала, а не рассчитанное
раскрытие. Флаги `physical_Gamma_selected` и `source_activation_accepted`
ложны. История, физика и допуск 2e−6 не изменены.

## Наблюдаемая величина и область доказательства

Вычисляется весь пространственный интеграл добавочной виртуальной работы,
в джоулях:

`W = integral H(Gamma) (Ghat_without_H a)^T C memoryhat det(X) dN1 dN2 dlambda`.

У этой пробы `mean_z_m = 0`; остальные добавочные члены (cross_parent и self)
равны нулю. Неизменная работа родительского тела и когезионная цена создания
поверхности в эту наблюдаемую величину не входят. Это не конечная энергия
раскрытия, критерий активации или её допуск.

Источник задаётся точными рациональными представлениями сохранённых чисел.
Сохраняется исходная конвенция представленных binary64 сумм X+P и A−P.
Пузырь `w = 27 N0 N1 N2 * 4 r(1-r) * (1-|x-center|²/R²)²`
дифференцируется символически. При u=N1, v=N2 используется тождество
`lambda grad(w) = w_u inv[0] + w_v inv[1] + (lambda w_lambda-u w_u-v w_v) inv[2]`,
где inv — обратная матрица столбцов (X1−X0, X2−X0, X0).
Два множителя 1/lambda деформации и памяти сокращают lambda² меры объёма;
дополнительный множитель lambda² в приведённой плотности не нужен.

Точный Cramer-сертификат ограничивает всю поддержку сферы внутри когорты.
Прямоугольник N1,N2 целиком лежит в симплексе; берётся весь интервал lambda.
На каждом блоке точная интервальная арифметика ограничивает сферу, Gamma
и плотность. Неопределённые части сферы сохраняются с включением нуля;
при неопределённом знаке Gamma используется H в [−1/2,+1/2]. Ничего
не отбрасывается по выборочным узлам. Плоскость Gamma имеет нулевой объём.

`audit.py` независимо воспроизводит арифметику графа, покрытие, отсечение,
все суммы, знак итогового интервала и стоимость. Он использует независимый
Cramer-аудитор, но не восстанавливает физическую формулу из первых принципов:
включение условно относительно описанного отображения источника в плотность.
Проверки плотности отдельной исходной алгеброй служат регрессией этого
отображения, а не доказательством интеграла по углу. Общие literal-константы
и функции их извлечения явно используются обоими путями.

## Ограниченные серии

В каждой серии предел 2000 обработанных блоков (родители тоже считаются),
глубина 24, 120 секунд с проверкой между делениями. Разбиение бинарное,
поэтому остановка по числу блоков произошла на 1999; глубина достигла 11.
Исходный и центрированный варианты сохранены раздельно ради проверки хешей.

| Блоков | Исходный интервал, Дж | Центрированный интервал, Дж |
|---:|---:|---:|
| 1 | [−6.473e11; +6.473e11] | [−9.572e9; +9.572e9] |
| 31 | [−2.291e10; +2.291e10] | [−8.154e8; +8.144e8] |
| 127 | [−4.596e9; +4.596e9] | [−2.381e8; +2.208e8] |
| 511 | [−7.187e8; +7.066e8] | [−6.099e7; +6.045e7] |
| 1999 | [−250271381.583; +242620371.242] | [−21965283.138; +23767573.001] |

Последние десятичные границы округлены наружу; точные дроби — в отчётах.
Второй проход проверял одну конкретную гипотезу: устранить избыточную
интервальную зависимость при вычислении x−center и Gamma. Это точная
билинейная перезапись около середины исходного прямоугольника.
`identity.py` подтвердил равенство всех коэффициентов трёх полиномов:
18 для сферы, 6 для Gamma, 468 для плотности. Это глобальное тождество,
не совпадение нескольких точек. Ширина включения уменьшилась в 10,78 раза.

Итог обоих проходов — **UNRESOLVED**: ноль остаётся внутри. Прежняя угловая
квадратура давала 962994,130676 Дж (грубая 961275,701166 Дж), наблюдаемую
оценку ошибки 61458,662742 Дж при allowance 1,925988 Дж. Она не является
независимой истиной или сертификатом положительного знака.

В финальном включении ширину 45,733 млн Дж дают: неопределённая сфера с
фиксированным Gamma 21,739 млн; неопределённые сфера и Gamma 2,988 млн;
внутри сферы с неопределённым Gamma 5,802 млн; внутри с фиксированным Gamma
15,205 млн. Следовательно, остаётся как геометрическая неопределённость,
так и переоценка диапазона плотности на блоках. Недостаточность любых
возможных методов при этом лимите не доказана.

Стоимость двух контроллеров: 3998 обработанных блоков, 2 214 892 посещения
узлов графа, 20,918 с. Первые независимые аудиты: 31,929 с и ещё 2 214 892
посещения. Финальная проверка после добавления контроля знака повторяет
эти аудиты; её время записано отдельно. Радиальных интегралов и механических
решений во всех этих действиях **0**. Каждый запуск двух адресных тестов
реальной плотности проверяет 6 точек; контроллеры вместе проверили ещё 6.
Число этих проверок не включается в стоимость регионального разбиения.

## Воспроизводимость и результат

`source_fixture.json` сохраняет только источник, пробу и исходный прямоугольник
из полного центрированного отчёта с его SHA256. Адресные тесты не требуют
внешнего полного отчёта. `summary.json` закрепляет результаты и локальные
полные сертификаты, содержащие графы, блоки, точные границы и исходные pins.
Полные отчёты хранятся в `/workspace`; в репозиторий они не копируются.

Запускать из корня, с проектным Python и ограничением BLAS/OMP до одного потока:

```sh
python -m pytest -q -p no:cacheprovider tests/test_genesis_regional_work.py
python -m analysis.genesis_regional_work_validation.run --output /workspace/NEW-original.json
python -m analysis.genesis_regional_work_validation.centered_run --output /workspace/NEW-centered.json
python -m analysis.genesis_regional_work_validation.audit --input /workspace/NEW-centered.json --output /workspace/NEW-audit.json
```

Команды контроллеров описывают воспроизведение, а не разрешение новой серии.
Для глобального сравнения выражений вызвать `identity.check` на полях `graph`
двух отчётов. Граница 5000 промежуточных полиномиальных членов не повышается.

Третья серия не запускалась. Минимальное следующее решение — ограниченный
метод, учитывающий совместную геометрию сферы/Gamma и интеграл знакопеременной
плотности, вместо простого увеличения числа прямоугольников. До такого решения
знак работы не установлен, физическое раскрытие не допущено; четыре больших
пространственных контроля и первый этап общего плана остаются открытыми.
